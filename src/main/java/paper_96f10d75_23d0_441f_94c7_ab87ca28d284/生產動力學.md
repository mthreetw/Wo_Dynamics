# 生產動力學

## 〇、定位與假定<!--句3972911508-->

本篇是承接上游的綱領論文，不新增機制。<!--句7090372898-->它在上游的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)、[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)、[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)、[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)循環之上，加一層研究者的記錄，描述各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)每一[推演輪](concepts.md#c07)的[解](concepts.md#c05)：下一刻的[狀態](concepts.md#c02)、[資源](concepts.md#c03)，以及是否[判準退場](concepts.md#c09)。<!--句0083633417-->對下游（例如暴力動力學）只提供一種記帳格式：[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)有[狀態變數](concepts.md#c02)與[資源變數](concepts.md#c03)；[資源變數](concepts.md#c03)在每一[推演輪](concepts.md#c07)有增減；[退場判準](concepts.md#c04)寫在[狀態變數](concepts.md#c02)上。<!--句0017038529-->

<note>

*這一篇是過渡性的綱領：不發明新機制，只給後面的論文一種記帳的格式。每個節點記兩種數字（狀態、資源），資源每推演輪會增減，是否判準退場看狀態上的判準。*

</note>

[生產](concepts.md#c01)是研究者對[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)的[分別](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c18)，不賦予[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)獨立本體。<!--句3722399613-->[資源](concepts.md#c03)、[狀態](concepts.md#c02)與[判準退場](concepts.md#c09)都是研究者的[分別](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c18)，本篇不預設三者之間有任何關係。<!--句1977714181-->

<note>

*「生產」不是輸出本身的性質，是研究者怎麼看那段輸出歷史。資源、狀態、判準退場三個東西也只是研究者的劃分，本篇不先假定它們互相有關。*

</note>

各節的「校準」與第六章的案例，只拿現實對照，不屬於推導的任何一部分，也不作推導來源。<!--句3080748781-->

<note>

*校準與案例只是拿現實來對照，不拿來證明什麼。*

</note>

本篇所稱[環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)，即上游的[自然環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)：在講明的[切法](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c23)下，不屬於任何[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)、卻有[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的部分。<!--句1058545450-->

<note>

*文中說「環境」，就是上游的自然環境，不是暗宇宙那篇的「環境」。*

</note>

## 一、律與前提<!--句0357609866-->

**承接。**<!--句7894646021--> [流變律](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c24)、[黑箱律](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c25)、[損耗律](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c26)、[不可復原律](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c28)；[渦](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c16)、[我](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c19)、[進場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c44)、[退場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c43)、[死亡](../paper_fb0addca_42b6_4884_aa18_438c695747ab/concepts.md#c22)、[自己的那一段](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c17)、[切法](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c23)、[自然環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)、[共振](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c09)、[文化](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c13)等，沿用上游定義，不重新定義。<!--句5025496044-->

<note>

*上游已經定義好的東西，這裡直接用，不重講。*

</note>

```text
前提一 範圍設定：研究者在講明的切法下，指定所選節點的邊界、
     狀態變數、資源變數，以及一條用狀態變數表述的退場判準，
     並報告是誰作這個劃分。本篇不預設資源、狀態與判準退場之間的關係。
附註 前提一是範圍設定，不是可被推翻的主張。
     適用範圍不限於人；人類視角下，退場判準常寫在生理狀態上，某個我據此標為死亡；
     判準退場依研究者所訂判準記錄，與上游的退場可以一致，也可以不一致，兩者不互相替代。
     判準可以是上游的「不再是渦」，也可以是生理界線、解散、退休等任一明示的定義。
附註 資源與狀態的界線隨節點邊界而定，沒有物件本身的固定歸屬。
     可轉移、可儲存是常用的辨認依據，不是定義：
     在某節點的視角下可轉移、可儲存者常記為資源，不可轉移、不可儲存者常記為狀態。
     研究者可以把與某個對象有關的變數，在不同節點、不同視角的切法下，
     歸入資源或狀態（例如義眼，或工人的勞動對工人與對老闆）。
附註 資源、狀態與判準退場的關係，本篇不預設。兩端都是研究者的分別，
     通則層寫不出內容；若有，屬具體切法下的經驗問題，
     由下游研究自行提出並承擔。
步驟一之一 退場判準是研究者的一次分別（從 前提一 + 切法 的定義 + 分別 的定義 + 退場判準 的定義 推出）
步驟一之二 判準講明後，某一推演輪是否判準退場，由該推演輪實際的狀態事件決定
     （從 前提一 + 前提二 + 步驟一之一 推出）
結論一之三 判準是定義，是否判準退場是事實，兩者不互相替代
     （從 步驟一之一 + 步驟一之二 + 退場判準 的定義 推出）
步驟一之四 什麼算某節點的狀態或資源，隨節點邊界而定，
     而邊界是研究者的一次分別（從 前提一 + 分別 的定義 + 同一 的定義 + 狀態變數 的定義 + 資源變數 的定義 推出）
結論一之五 資源與狀態的歸類是切法下的歸類，不是事物本身的性質
     （從 前提一 + 步驟一之四 推出）
```
<!--句6760469038-->

<note>

*前提一是範圍的設定：研究者先講明怎麼切、記哪些數字、拿什麼當判準退場的標準。它不是會被證明對或錯的主張。後面幾條是從它直接推出來的。*

</note>

**校準。**<!--句6299769767--> 退休算[判準退場](concepts.md#c09)，生理狀態達到指定的界線也算[判準退場](concepts.md#c09)（常被某個[我](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c19)標為[死亡](../paper_fb0addca_42b6_4884_aa18_438c695747ab/concepts.md#c22)），公司解散也是[判準退場](concepts.md#c09)，各由使用者定義，所以[判準](concepts.md#c04)是定義；某個人在某一[推演輪](concepts.md#c07)是否真的退休或達到該界線，才是事實。<!--句4478043346-->義眼算不算他的一部分，義眼使用者與保險公司可以各有說法；工人的心情與體力，對他自己是[狀態變數](concepts.md#c02)，工人投入的勞動，對老闆是可取得的[資源變數](concepts.md#c03)。<!--句5626317270-->這是校準，不是推導來源。<!--句3122505271-->

<note>

*用日常的例子看：「怎樣算判準退場」是我們規定的，「這個人今天有沒有真的退休或死」是發生了沒有。同一個東西在不同人的帳裡，可以一邊記成狀態，一邊記成資源。*

</note>

### 禁止清單（方法上禁止）<!--句2377519808-->

1. 不把[判準](concepts.md#c04)當作事實，也不把[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)推測當作判定。<!--句4655725210-->
2. 不由[資源變數](concepts.md#c03)的增減記錄，推出這次增減屬於哪一類[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)，或推出動機與正當性。<!--句1114273998-->
3. 不跨[切法](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c23)加總[資源變數](concepts.md#c03)與[狀態變數](concepts.md#c02)。<!--句8504334623-->
4. 不由存續推最優，不由變異推改善。<!--句8287708283-->
5. 不替所有權、正當性預設前件。<!--句7319009473-->
6. 不把某一種歸類當成事物本身的性質（例如「眼睛是狀態」「錢是資源」），須連同[切法](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c23)一起說。<!--句8889819378-->
7. 不替[資源](concepts.md#c03)與[判準退場](concepts.md#c09)預設關係；要主張，須先定義具體的[資源](concepts.md#c03)與具體的[退場判準](concepts.md#c04)。<!--句1480471936-->
8. 不談資源是否「移動」：移動預設[同一性](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c21)，而[同一](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c21)是[分別](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c18)；本篇只記各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)[資源變數](concepts.md#c03)的增減。<!--句4629394187-->
9. 不把「篩選」「淘汰」當作有目的的過程，只作比喻。<!--句7961101009-->

<note>

*九條「不准這樣推」的清單，每一條都是在防止把帳目讀成動機、因果或價值判斷。*

</note>

## 二、模型<!--句3047017555-->

本篇把模型往前推進一次的單位稱為[推演輪](concepts.md#c07)：在講明的[切法](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c23)下，在場的各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)各走一次上游的循環，再加上研究者所作的記錄，以及成員的變動。<!--句8487355662-->單位是整個切出的範圍，不是單一[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)；記錄什麼、成員怎麼變動，由使用者指定；不假定各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)同步，[推演輪](concepts.md#c07)只是排序。<!--句8806552742-->

<note>

*「推演輪」是本篇自己取的名字：模型往前走一步，所有人各做一次該做的事，研究者記下來，有人判準退場有人進場。它和上游「回合」不是同一個東西：回合只管一個渦自己走的一圈，推演輪管整個範圍的一整步。*

</note>

本篇的模型是按[推演輪](concepts.md#c07)推進的遞迴，沿用上游的循環。<!--句0618818843-->每一[推演輪](concepts.md#c07)，各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)，[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)自己、其他[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)與[環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)，[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)的物理改變進入[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)。**<!--句2651249350-->求[解](concepts.md#c05)就是：我現在[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)，下一刻我會變成什麼樣子；那個樣子就是這一[推演輪](concepts.md#c07)的[解](concepts.md#c05)。**<!--句5728031267--> 單人與多人用同一個模型：多人只是研究者把原本放在[環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)裡的一部分切出來當成[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)，各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)互相進入對方的下一刻。<!--句3859370048-->

<note>

*整個模型一句話：我現在做了什麼，下一刻我變成什麼樣，那個「樣子」就是這推演輪的答案。一個人或很多人都用這個式子，差別只在研究者有沒有把別人也切成節點。*

</note>

```text
前提二 推演輪結構：每一推演輪依下列六步進行
推演輪步驟一 輸出　 在場的各節點，依各自歷史所決定的權重，落出輸出。　　　　　（上游）
推演輪步驟二 到達　 輸出到達節點自己，也到達其他節點與環境。　　　　　　　　　（上游）
推演輪步驟三 回應　 自然環境回應；其他節點也各自落出輸出。這些都可能到達本節點。
                  自然環境內部是什麼，本篇不問。
推演輪步驟四 入史　 到達節點的一切物理改變，不論來自自己的輸出、其他節點的輸出
                  或環境的回應，都進入該節點的歷史，參與後續權重。
                  權重由歷史決定，不可讀。　　　　　　　　　　　　　　　　　（上游）
推演輪步驟五 解　　 研究者在切法下記錄各節點下一刻的狀態變數、資源變數，
                  並依退場判準記錄各節點是否判準退場。這些合起來，就是本推演輪的解。
推演輪步驟六 成員變動 判準退場者不再參與，其歷史仍在；進場者加入，前史可與既有節點重疊。
回到推演輪步驟一。
本篇的循環沒有內建的退出條件；是否停止，由研究者在模型之外指定。
```
<!--句2865019849-->

<note>

*一推演輪的六個動作：先各自輸出，輸出到達各處，環境和別人回應，一切進入歷史，然後研究者把下一刻的狀態、資源、是否判準退場記下來（這就是「解」），最後有人判準退場、有人進場，再開始下一推演輪。*

</note>

```text
定義 解：研究者在講明的切法下，記錄的各節點下一刻的狀態變數、資源變數，
     以及依退場判準所記的是否判準退場，合起來是本推演輪的解。
附註 判準退場只是解的一個維度，與其他維度並列，沒有特別地位。
附註 沒有記錄的東西不在解裡，但仍在歷史中。
```
<!--句3321236901-->

<note>

*「解」就是研究者這推演輪記下來的那一包數字。沒記的就不在裡面。判準退場只是其中一欄。*

</note>

**說明**<!--句7332127501-->

1. [歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)包含所有[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的物理改變。<!--句1739424823-->沒被記錄的部分仍在[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)裡，繼續影響[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)。<!--句0430677937-->
2. [解](concepts.md#c05)不預設最優，也不預設與目的或資源有關。<!--句1359711162-->[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)是否[判準退場](concepts.md#c09)，只是現實給的限制：一個人下一刻是否被車撞死，與他想要什麼、有多少資源，都沒有必然關係。<!--句2194821254-->
3. 目的若表現為各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)對自己的[分別](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c18)，就進入[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)，只經[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)影響後續[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)；本篇不確認、不預設其內容（承接上游[驅動力不可確認](../paper_ae79e938_76e1_4bf9_b2ab_995c03e16c9e/concepts.md#c03)）。<!--句0224293038-->
4. 多人時，一個[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的[解](concepts.md#c05)可能同時受自己的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)與其他[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)影響；各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)下一刻合起來，就是整個切出範圍的[解](concepts.md#c05)。<!--句0083351253-->每個人各自[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)，彼此的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)進入對方的下一刻，求[解](concepts.md#c05)因此是多人共同發生的過程，不是各記各的帳。<!--句7852974921-->
5. 本篇的記錄只涵蓋物理改變。<!--句2396969540-->[分別](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c18)（對自己或他人的看法）也會進入[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)，沿用上游，不在本篇記錄。<!--句7519049399-->
6. 不假定各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)同步，[推演輪](concepts.md#c07)只是排序，沿用上游。<!--句2412220025-->
7. 本篇不規定回應是什麼、增減多少。<!--句9195497312-->同樣的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)，今天與明天的回應可以不同。<!--句4222586244-->
8. 本篇的[推演輪](concepts.md#c07)循環沒有內建的退出條件；是否停止，由研究者在模型之外指定。<!--句7721087047-->[判準退場](concepts.md#c09)只處理個別[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)，不是整體的終止條件。<!--句7261454543-->

<note>

*八點補充：記錄不等於全部歷史；解不代表最優；目的不去猜；多人時大家一起影響彼此；看法也會進歷史但本篇不記；不要求同步；也不規定環境怎麼回應；整體推演何時停止，由研究者在模型之外指定，判準退場不是整體終止條件。*

</note>

**校準。**<!--句6299769767--> 我去挖礦，[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)的是勞力；礦山回應，我下一刻手上多了一塊礦石，體力下降，這就是我這一[推演輪](concepts.md#c07)的[解](concepts.md#c05)。<!--句7613693931-->明天同樣挖，礦石不一定出現。<!--句0465650169-->另一個人走在路上要去喝酒，被車撞死：他的[解](concepts.md#c05)裡，是否[判準退場](concepts.md#c09)這一維度記為[判準退場](concepts.md#c09)；這與他想要什麼、有多少資源無關，只是現實給的限制。<!--句8735936184-->這是校準，不是推導來源。<!--句3122505271-->

<note>

*兩個日常例子：挖礦，今天有礦明天不一定有；被車撞死跟想不想喝酒、有沒有錢無關。*

</note>

### 多人時的命名<!--句5955499078-->

多人時，各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)互相進入對方的下一刻。<!--句1021402942-->在[生產](concepts.md#c01)維度上，若這些[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)彼此[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)，並在講明的時窗內序列反覆相容接續，即為上游所稱的[共振](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c09)；若再滿足上游對[文化](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c13)的條件，則[共振](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c09)留下的相容圖樣，是上游所稱的[文化](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c13)在[生產](concepts.md#c01)維度上的呈現。<!--句5023600071-->[資源變數](concepts.md#c03)是被記錄的變數，不參與[共振](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c09)。<!--句5510855591-->交換、傳遞、合作、掠奪等，是研究者對這類[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)序列的命名，不是模型的組成，也不由帳目讀出（見五之六）。<!--句5647271707-->

<note>

*多人時，如果大家的輸出一次次接得上，上游叫它共振；交換、合作、掠奪這些名字是研究者貼的標籤，不是帳目裡寫著的。*

</note>

把若干[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)合成一個，或把一個拆成若干[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)，是[重切](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c22)。<!--句9623960787-->若要主張粗細兩種記錄的[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)一致，須講明粗記錄所問的結果如何由細記錄得到；未講明者，只能各自報告，不互相推論。<!--句9277755527-->

<note>

*把幾個人合成一個單位來記，或把一個單位拆開，是換一種切法來記。但粗記錄和細記錄的權重要不要說一致，得先講明粗的怎麼由細的得出。*

</note>

### 由模型推出的性質<!--句2458374912-->

```text
結論二之一 權重讀歷史；解的記錄本身不是權重的直接輸入；解的記錄是研究者的選取
     （從 生成函數 的定義 + 前提二 + 解 的定義 推出）
結論二之二 歷史只加不減，路徑依賴；資源變數依實際事件可增可減，本篇不對記錄的變數設定不可逆限制
     （從 歷史 的定義 + 不可復原律 + 前提二 + 前提四 推出）
結論二之三 判準退場只是解的一個維度；判準只對被記錄的狀態變數作判定，不對歷史全體，也不對權重
     （從 前提一 + 結論一之三 + 前提二 + 解 的定義 推出）
結論二之四 對不被鎖死的渦，同樣的輸出不保證得到同樣的解
     （從 黑箱律 + 鎖死 的定義 + 權重 的定義 + 流變律 + 輸出 的定義 + 解 的定義 + 前提二 推出）
結論二之五 多人時，其他節點的輸出可能到達本節點，到達後進入歷史、參與後續權重，
     因此一個節點的解可能受自己與其他節點的輸出共同影響
     （從 前提二 推出）
結論二之六 每推演輪成員可能變動；成員變動時，各節點的歷史與共振條件可能隨之變
     （從 流變律 + 進場 的定義 + 判準退場 的定義 + 共振 的定義 + 前提二 推出）
結論二之七 本模型不要求解最優、守恆、收斂或平衡
     （從 前提一 + 前提四 + 解 的定義 推出）
結論二之八 本模型不指定回應的內容與增減的數量，因此不能預測軌跡
     （從 前提二 + 前提四 + 解 的定義 推出）
結論二之九 多人時，在生產維度上，若節點的輸出彼此到達，並在講明的時窗內序列反覆相容接續，即為共振；若再滿足上游對文化的條件，則共振留下的相容圖樣，是文化在生產維度上的呈現
     （從 前提二 + 共振 的定義 + 文化 的定義 + 生產 的定義 推出）
結論二之十 粗細兩種記錄的權重是否一致，不由重切的定義保證；要主張一致，須講明粗記錄所問的結果如何由細記錄得到，未講明者只能各自報告，不互相推論
     （從 重切 的定義 + 權重 的定義 推出）
結論二之十一 目的若表現為節點對自己的分別，則它進入歷史，並只經權重影響後續輸出；本篇不確認也不預設目的的內容
     （從 分別 的定義 + 歷史 的定義 + 權重 的定義 + 生成函數 的定義 + 前提二 + 驅動力不可確認 推出）
結論二之十二 本篇的記錄只涵蓋物理改變；分別進入歷史，不在本篇的記錄範圍內
```

<note>

</note>

### 這個模型不是什麼<!--句1809371978-->

它不規定回應是什麼、增減多少，所以**不能預測軌跡**，只能說記什麼、哪條線與哪條線在何處相交、哪些性質可推。<!--句3111321759-->實際的[解](concepts.md#c05)要由具體案例提供資料或規則。<!--句9509142847-->層級沿用上游互動動力學各篇的做法：轉移不指定，只推定性性質。<!--句6540175539-->

<note>

*這個模型不能用來預測。它只告訴你記什麼、能推出哪些性質。真正的數字要由具體案例提供。*

</note>

## 四、人類視角（前提一的實例）<!--句1681178149-->

人類視角下，[退場判準](concepts.md#c04)常寫在生理狀態上，某個[我](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c19)據此對[渦](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c16)標上[死亡](../paper_fb0addca_42b6_4884_aa18_438c695747ab/concepts.md#c22)；本篇的[判準退場](concepts.md#c09)依研究者所訂判準記錄，與上游的[退場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c43)可以一致，也可以不一致，不互相替代；[狀態變數](concepts.md#c02)例如體力、能量儲備、生理狀態，[資源變數](concepts.md#c03)例如食物，由研究者指定。<!--句7700218490-->出生只是[進場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c44)：[進場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c44)者的前史若含親代的生物性原材料，那是[進場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c44)時的前史重疊，不另立事件。<!--句7849344871-->親代的生物性原材料與[學習](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c04)分開：前者是生物構成，後者沿用上游的[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)與[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)，不保證複製親代的知識、[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)或[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)。<!--句2241528541-->

<note>

*把前提一套到人身上：退場判準常寫在生理狀態上，死亡是某個我作的標記，體力和食物各是狀態和資源。出生只是一次進場；親代給的身體材料，不等於把親代的經歷或傾向也傳給孩子。*

</note>

```text
步驟四之一 進場者的前史可能與既有節點重疊
     （從 前提二 推出）
結論四之二 進場者的前史即使與既有節點重疊，也不蘊涵他繼承親代的歷史、權重或輸出
     （從 步驟四之一 + 到達 的定義 + 歷史 的定義 + 權重 的定義 + 輸出 的定義 + 學習 的定義 推出）
```

### 五之二　權重推測不能替代判定<!--句3141630626-->

本節與五之五所稱「不被[鎖死](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c12)」，依上游[鎖死](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c12)的定義。<!--句3686779431-->

<note>

*「不被鎖死」就是上游講的：下一刻有不只一種可能結果。*

</note>

```text
步驟五之二之一 我對渦的權重推測（上游稱印象）的對象是分支的輕重，
     判定的對象是已發生的事件
     （從 權重 的定義 + 印象 的定義 + 步驟一之二 推出）

     是否判準退場仍須由實際事件判定，不能以權重推測替代
     （從 步驟一之二 + 步驟五之二之一 + 步驟五之二之二 推出）
```

### 五之三　已發生的進場不被取消<!--句3857686981-->

```text
步驟五之三之一 退場不刪除歷史中已發生的位置
     （從 歷史 的定義 推出）
步驟五之三之二 是不是渦由實際的歷史決定；進場是開始成為渦（包括第一個時刻就是渦的情形），
     退場是不再是渦；每一次退場，都在其對應的那一次進場之後
     （從 歷史 的定義 + 渦 的定義 + 進場 的定義 + 退場 的定義 推出）
步驟五之三之三 退場的渦，自己的那一段仍在歷史中
     （從 退場 的定義 + 歷史 的定義 + 自己的那一段 的定義 推出）
結論五之三之四 退場不取消已發生的進場，也不取消進場者留下的到達
     （從 步驟五之三之一 + 步驟五之三之二 + 步驟五之三之三 + 到達 的定義 推出）
附註 判準退場是研究者的記錄，不改變歷史。
```
<!--句2903673102-->

**校準。**<!--句6299769767--> 一個人生下孩子之後[退場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c43)：孩子的[進場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c44)與他自己的[退場](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c43)，都在[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)裡各占一個位置，後者不取消前者。<!--句8951339170-->這是校準，不是推導來源。<!--句3122505271-->

<note>

*已經發生的進場不會因為後來有人退場就變成沒發生過。*

</note>

### 五之四　資源變數的來源歸屬不影響判定方式<!--句7226386278-->

```text
步驟五之四之一 若節點的資源變數在某推演輪有增加，則該增加是實際事件的記錄
     （從 前提四 推出）
步驟五之四之二 是否把這次增加記為與其他節點的輸出相關，是研究者的歸屬
     （從 分別 的定義 + 輸出 的定義 + 前提四 推出）
步驟五之四之三 在同一切法內，某推演輪是否判準退場，只看狀態變數與判準，
     不看資源變數的來源歸屬
     （從 前提一 + 步驟一之二 推出）
結論五之四之四 資源變數的增加如何歸屬，不改變是否判準退場的判定方式；
     本篇不由此推出資源與狀態的關係
     （從 步驟五之四之二 + 步驟五之四之三 推出）
附註 這不推出其他節點有給予的意圖，也不推出整個網路的資源總量增加；
     前者受驅動力不可確認約束，後者須在同一切法內另行核算。
```
<!--句7060052207-->

**校準。**<!--句6299769767--> 一個窮人一天只吃一碗飯，一個有錢人可以吃牛排、火雞與各式漢堡，兩人的[資源變數](concepts.md#c03)很不一樣，但沒有任何道理說窮人必須立刻[判準退場](concepts.md#c09)。<!--句2744220602-->反過來，一個有錢人走在路上被車撞死，他死不是因為慾望，也不是因為資源不足。<!--句0681132220-->[判準退場](concepts.md#c09)與想要什麼、有多少資源都沒有必然關係，只是現實給的限制。<!--句8328143593-->這是校準，不是推導來源。<!--句3122505271-->

<note>

*資源增加是怎麼來的，是研究者的說法；判定有沒有判準退場，只看狀態和判準，跟資源從哪來無關。*

</note>

### 五之五　變異與篩選不蘊涵改善、最優或永續<!--句7903782234-->

```text
步驟五之五之一 對不被鎖死的渦，由歷史決定的權重只推出傾向，結果可變異
     （從 黑箱律 + 鎖死 的定義 + 權重 的定義 推出）
步驟五之五之二 本篇不要求退場判準含有任何「較優」的條件；
     判準只是研究者指定的一條用狀態變數表述的條件
     （從 前提一 推出）
步驟五之五之三 判準是否被滿足，與資源變數的變化各自記錄，
     本篇不推出兩者的關係
     （從 前提一 + 前提二 推出）
結論五之五之四 輸出變異與判準退場記錄，不足以推出狀態或資源的單調改善、最優或永續
     （從 步驟五之五之一 + 步驟五之五之二 + 步驟五之五之三 + 結論二之二 + 輸出 的定義 + 退場判準 的定義 + 判準退場 的定義 推出）
附註 「篩選」在上游只作比喻，須標明是比喻。
```

### 五之六　增減記錄不蘊涵輸出類型<!--句1079948435-->

```text
步驟五之六之一 資源變數的增減，是相關節點各自的記錄，由實際事件決定
     （從 前提四 推出）
步驟五之六之二 輸出到達對方後，進入對方的歷史
     （從 前提二 + 輸出 的定義 + 到達 的定義 + 歷史 的定義 推出）
結論五之六之三 若資源變數只記數值增減、不含輸出類型的資訊，則資源變數的帳目只記數值增減；輸出類型是研究者另行加上的分類標記，
     不在資源變數帳目的記錄範圍內，故不由資源變數的帳目讀出
     （從 前提一 + 步驟五之六之一 + 步驟五之六之二 + 解 的定義 推出）
附註 動機、需求與目的受驅動力不可確認約束，不由帳目讀出；
     這只限於動機，不當作類型不可辨識的充分證明。
附註 暴力、交換、贈與、欺騙等，是研究者對輸出的命名，不是模型的組成。
附註 本篇不替所有權與正當性預設前件。
```
<!--句9486557784-->

**校準。**<!--句6299769767--> 暴力、賄賂、恐嚇、詐欺，在帳目上看，都只是有人的某個[資源變數](concepts.md#c03)減少、有人的增加；它們的差別在[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)與[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)的內容，由研究者命名。<!--句6135634636-->這是校準，不是推導來源。<!--句3122505271-->

<note>

*帳目只看得到「誰多了、誰少了」，看不出是搶、是騙還是送；那是研究者事後貼的名字。*

</note>

### 五之七　資源與狀態的邊界是切法<!--句7893397929-->

```text
步驟五之七之一 研究者可以在不同節點、不同視角的切法下，
     各自記下與某個對象有關的資源變數或狀態變數
     （從 結論一之五 + 前提三 推出；例如研究者可在住戶與國家領土兩個節點的帳目裡，
      各自記下與一棟房子有關的變數；工人的勞動對工人記為狀態，對老闆記為資源）
結論五之七之二 不同節點的帳目裡出現與同一對象有關的變數，不構成矛盾，
     也不推出所有權的歸屬，也不預設這些變數指的是同一件東西
     （從 步驟五之七之一 + 前提三 + 同一 的定義 推出）
步驟五之七之三 跨切法的變數，範疇各由自己的切法決定，本篇不預設它們指同一件東西；
     與同一對象有關的變數若直接相加，重複計算只是其中一種後果
     （從 結論一之五 + 結論五之七之二 推出）
結論五之七之四 本篇不主張資源在節點之間「移動」，只記各節點的資源變數的增減
     （從 前提四 推出）
附註 本篇不跨切法加總資源變數與狀態變數（禁止清單第三項）；總量只在同一切法內核算；不同切法的結論不直接互推。
附註 移動預設同一性，而同一是分別；這是本篇不談移動的理由，不是推導來源。
附註 在本篇例示的切法下，工人是節點，不是資源；老闆的切法下記錄的是工人的勞動（輸出）所對應的資源變數。
```
<!--句9459796894-->

**校準。**<!--句6299769767--> 一塊土地可以同時是私人的，也是國家的領土；兩邊的帳目各自有各自的記法，並不衝突。<!--句8192884254-->這是校準，不是推導來源。<!--句3122505271-->

<note>

*同一塊地，住戶的帳和國家的帳各記各的，不衝突，但兩邊的數字不能直接加起來。*

</note>

### 6.1 北美大平原的水牛跳崖獵場<!--句2917030037-->

**經過。**<!--句2988483463--> 在北美大平原，人們把整群水牛趕下懸崖，在崖底宰殺。<!--句4884041369-->加拿大亞伯達省的〔Head-Smashed-In〕是其中最大、最老的一處：崖高約十到十八公尺，使用從約五千七百年前延續到十九世紀中葉。<!--句4192225232-->崖頂是水草豐美的牧場，從崖西十公里處起，有五百多座石堆排成驅趕線，人們在石堆旁生火或揮舞毯子，把牛引向崖緣。<!--句9473973939-->

一次驅趕不是一天的事。<!--句1924691036-->石堆要先蓋好，並隨年代修補；各處的獵場也各有儀式，例如黑腳族相信海洋化石能吸引水牛，狩獵前的儀式裡有它的位置。<!--句2653273849-->到了當天，先選定一群牛，一名獵人披上小牛的皮，學小牛受驚的叫聲，把牛群引進驅趕線；另一些人可能披著狼皮，從後面逼；石堆上立著稻草人或堆著樹枝，石堆旁的人揮動毛皮，讓牛群愈跑愈快。<!--句0813568747-->獵場常選在地形起伏處，崖緣被遮住，牛看見時已無法回頭。<!--句8576044412-->披小牛皮的人要在最後一刻閃開，但有許多他墜崖而死的記載。<!--句3243850329-->

牛墜崖後，人們在崖底下方的營地處理：崖底的骨骸在某些地方深達十一公尺，營地綿延約一公里，留有肉窖與烹煮坑，地下還有近一公尺厚的碎骨。<!--句1660551305-->蒙大拿的考古也找到加熱油脂與烘烤的坑，用來把肉做成與油脂、漿果混合的肉餅（〔pemmican〕），肉餅與毛皮都是交易物。<!--句5830514560-->獵場在十九世紀中葉後不再使用，當時水牛已近絕跡。<!--句5148167600-->

<note>

*先講故事：把牛群引進石堆排成的通道，披小牛皮的人學叫聲引路，兩旁的人揮毛皮逼牛，牛衝下懸崖，崖底的人處理牛肉與牛皮。引誘的人有時跟著摔死。*

</note>

**帶入框架。**<!--句2935150531--> 先選[切法](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c23)：[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)是引誘者、石堆旁的人、後方逼趕的人、崖底處理的人，以及更早蓋石堆、修石堆的人；牛群與地形留在[自然環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)，本篇不問牛群內部。<!--句9987839032-->

先看一個驅趕當天的[推演輪](concepts.md#c07)。<!--句1909575735-->引誘者披皮學叫，是[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)，[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)牛群；牛群朝他移動，是[自然環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)的回應，這個移動[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)引誘者，也[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)石堆旁的人，成為各人[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)的一部分。<!--句0996865643-->石堆旁的人依這段[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)落出下一個[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)，揮動毛皮，牛群的移動又變了一次。<!--句1463154774-->這一[推演輪](concepts.md#c07)的[解](concepts.md#c05)，是各人下一刻的[狀態變數](concepts.md#c02)與[資源變數](concepts.md#c03)：引誘者仍在線上，崖底的人手上還沒有肉；牛群離崖更近，是[自然環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)的變化，不在[解](concepts.md#c05)裡。<!--句9682812880-->

再看最後一個[推演輪](concepts.md#c07)。<!--句9790643665-->引誘者閃開或墜崖，這是現實給的結果：若[退場判準](concepts.md#c04)取生理狀態的指定界線（墜崖者常被標為[死亡](../paper_fb0addca_42b6_4884_aa18_438c695747ab/concepts.md#c22)），墜崖者在這一[推演輪](concepts.md#c07)記為[判準退場](concepts.md#c09)。<!--句9889921130-->他的[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)仍在，他的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)已[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)的牛群與同伴，也不因此取消（五之三）。<!--句4422664447-->崖底的[推演輪](concepts.md#c07)，各人的肉與皮的[資源變數](concepts.md#c03)增加，增加多少由當次事件決定；下一次牛群未必進線，同樣的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)不保證同樣的[解](concepts.md#c05)（結論二之四）。<!--句2595624030-->

最後把時間拉長。<!--句3838657319-->蓋石堆的人把[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)留在地上，一代一代[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)後來的人，成為他們[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)的一部分；更早的[推演輪](concepts.md#c07)因此影響更晚的[解](concepts.md#c05)。<!--句7846411978-->各[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)彼此[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)，在這段時窗內於[生產](concepts.md#c01)維度上反覆相容接續，這是上游所稱的[共振](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c09)，其留下的相容圖樣，可看作[文化](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c13)在[生產](concepts.md#c01)維度上的呈現。<!--句8213502972-->研究者稱這種接續為合作、分工，是命名，不由帳目讀出。<!--句2725644757-->

<note>

*再用本篇的記法走一遍：先決定誰算節點、牛群留在環境；一推演輪裡引誘、牛群反應、旁人揮毛皮，一環扣一環；最後一推演輪有人墜崖，就記成判準退場；崖底推演輪各人的肉和皮增加；長期看，蓋石堆的人的輸出一代代留下來，各人的動作反覆接得上，上游叫它共振，我們叫它合作是貼標籤。*

</note>

**可說與推不出。**<!--句2987056525--> 可說：在這些來源的描述裡，多人的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)序列反覆接續，有人因此墜崖而[判準退場](concepts.md#c09)，有人因此取得肉與皮。<!--句3982671926-->推不出：每個人分得多少、誰指揮誰、各人的動機。<!--句9733846927-->來源中有人把這套安排歸為社團與儀式主導，也有人說「每處不同」，這些是來源的歸屬，也推不出每次驅趕的過程相同。<!--句8652866586-->

**資料說明。**<!--句2424042824--> 過程細節（小牛皮、狼皮、海洋化石、肉餅）主要來自一篇談蒙大拿黑腳族獵場的考古報導，該文說各處不同、大致如此；〔Head-Smashed-In〕的來源只用來提供年代、規模、崖底營地與骨層。<!--句3684545472-->獵後如何分肉與分配、各社團的具體分工、個別參與者的體力或傷亡資料，沒有讀到，不寫。<!--句9887360528-->

<note>

*能說的只有「有人反覆接力、有人摔死、有人得到肉和皮」；每個人分多少、誰指揮誰、為什麼，來源沒說清楚，就不寫。細節多半來自蒙大拿的報導，不是這一處本身。*

</note>

### 6.2 福特〔Highland Park〕的移動裝配線<!--句0682369852-->

**經過。**<!--句2988483463--> 一九〇三年成立的福特汽車，兩年內就做到一天二十五輛，但那時造車是靜止的：底盤停在原處，工人帶著零件過來，什麼都做一點，最快的紀錄是十二小時十三分。<!--句0124284806-->

一九一三年四月，飛輪磁電機先上了移動線。<!--句7224893554-->原本一個工人約二十分鐘做完一個，現在把工序拆開，一個人只裝一個零件就推給下一個人；產出先縮到十三分鐘，再縮到五分鐘。<!--句4760203870-->接著引擎、變速箱也上了線；同年夏秋之間，底盤也用繩索與絞盤拉過工作區，工人沿線裝零件，一輛車降到五、六小時，一九一四年縮到九十三分鐘，一天可產約一千輛。<!--句2302550776-->車價下降，福特稱這是讓中產階級買得起車的夢想。<!--句9984676424-->

代價落在工人身上。<!--句5317920097-->許多技術工人覺得這份工作單調而疲憊；工廠裡多數是新移民，至少五十三個國籍、說一百多種語言，公司要求他們上英語學校。<!--句2860448146-->一九一三年底離職率達百分之三百八十，公司要增加一百人，得雇用九百六十三人。<!--句5336733261-->一九一四年一月，公司宣布八小時五美元，先前是九小時二點三四美元，並說會把利潤分一部分給工人。<!--句7779592362-->實際上，這份工資只給調查過私生活、被認為「合格」的人。<!--句5182247437-->工作並沒有變輕鬆，步調也沒有變慢，但隔天早上，一萬人聚在廠門口等著求職。<!--句4251183314-->

<note>

*先講故事：以前一個人包辦一輛車，要十幾個鐘頭；改成每人只做一個小動作、車子沿線移動後，一輛車只要一個半鐘頭。但工人受不了，一年離職率三倍多；公司於是把日薪加到五美元，隔天上萬人來排隊。*

</note>

**帶入框架。**<!--句2935150531--> 先選[切法](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c23)：各工位的工人與公司是[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)；機器、傳送帶與零件留在[自然環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)，本篇不問其內部。<!--句2979635545-->

先看磁電機線的一個[推演輪](concepts.md#c07)。<!--句3747133619-->一名工人把一個零件裝上，是[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)；傳送的動作與半成品的移動，是[自然環境](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c16)的回應，[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)下一個工人，成為他[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)的一部分，他依此落出下一個動作。<!--句1580359262-->這一[推演輪](concepts.md#c07)的[解](concepts.md#c05)，是各人的經手零件數、體力與是否仍在崗。<!--句9431281248-->這串[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)之所以能接成一條線，是因為每個人的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)都剛好進入下一個人的下一刻；各工人的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)序列在班次內反覆相容接續，這是上游所稱的[共振](../paper_2ccbf179_58cf_4851_bd72_5fa886e4b2c3/concepts.md#c09)，研究者稱它合作[生產](concepts.md#c01)，是命名。<!--句3439645137-->

再看離職。<!--句5652982934-->[退場判準](concepts.md#c04)取離職，由本文作者指定：百分之三百八十是這個[判準](concepts.md#c04)下的事實，[判準](concepts.md#c04)本身是定義，兩者不互相替代（結論一之三）。<!--句4414705551-->離職是一些[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)在某一[推演輪](concepts.md#c07)的[解](concepts.md#c05)的一個維度，與他們是否想要什麼、有多少資源，沒有必然關係；一個人下一刻是否離開，仍然只能由[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)推到傾向，推不到結果。<!--句5726956664-->

薪資與勞動，是兩個[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)各自記的變數：勞動對工人是[狀態變數](concepts.md#c02)（體力與心情），對公司是[資源變數](concepts.md#c03)；工資的增減各自記帳（五之七）。<!--句9510264708-->公告五美元，是一次新的[到達](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c10)，進入許多人的[歷史](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c13)，改變他們下一刻的[權重](../paper_37b3643a_dc40_4463_8b36_4f4594acd986/concepts.md#c06)；一萬人到廠門口，是其中一些[節點](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c25)下一個[推演輪](concepts.md#c07)落出的[輸出](../paper_b9df3b68_23ee_4839_965b_ed0e6b283ee6/concepts.md#c28)。<!--句2072859054-->

<note>

*再用本篇的記法走一遍：工人和公司是節點，機器和零件留在環境；一推演輪裡，一個人裝零件，車子往下一站移，下一個人接著做；離職率是我們指定「離職就算判準退場」之後的事實；薪水和勞動各自在不同的帳裡；公告加薪是一次新的到達。*

</note>

**可說與推不出。**<!--句2987056525--> 可說：裝配線引入後，離職率很高，這是一件事實；加薪公告後，大批人聚到廠門口，是另一件事實。<!--句7614022742-->推不出的是動機與關係：公共電視的頁面把加薪寫成為了降低離職，福特博物館把它寫成工人以接受裝配線紀律換取高薪，這是來源各自的歸屬，依[驅動力不可確認](../paper_ae79e938_76e1_4bf9_b2ab_995c03e16c9e/concepts.md#c03)，不由帳目讀出；也推不出加薪使離職減少，因為本篇不預設[資源](concepts.md#c03)與[判準退場](concepts.md#c09)的關係，那是下游的經驗問題。<!--句4490506029-->

**資料說明。**<!--句2424042824--> 底盤上線的日期，各來源說法不一（八月或十月七日），正文寫「夏秋之間」。<!--句7791616860-->「利潤分一部分給工人」只見於公共電視頁面。<!--句9300788119-->工人個人的疲勞、薪資用途、各工位的實際動作，沒有讀到，不寫。<!--句3769536920-->

<note>

*能說的是離職率高、加薪後人潮來了；至於加薪是為了留人，還是工人拿紀律換高薪，兩個來源各說各的，我們不替它們定論。*

</note>
