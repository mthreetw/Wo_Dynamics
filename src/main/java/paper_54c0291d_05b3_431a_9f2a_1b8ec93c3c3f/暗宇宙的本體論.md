# 暗宇宙的本體論

## 框架宣告

[奇點](concepts.md#c01)沒有[時刻](concepts.md#c04)。

[時刻](concepts.md#c04)從[奇點](concepts.md#c01)之後開始。[奇點](concepts.md#c01)沒有之前。[奇點](concepts.md#c01)不可被形式化。

本框架描述的是：[時刻](concepts.md#c04)已經開始，[刺激](concepts.md#c07)已經[出現](concepts.md#c08)，[信](concepts.md#c26)已經[累積](concepts.md#c30)，沒有觀察者的宇宙。這個宇宙，就是[形式層](concepts.md#c02)。

[形式層](concepts.md#c02)沒有觀察者，但有[給定](concepts.md#c03)。[給定](concepts.md#c03)是[形式層](concepts.md#c02)無法自己產生的東西。本框架的原則是：**不可推出的東西，越少越好；凡不可推出的，一律明列。[形式層](concepts.md#c02)中只有明列的[給定](concepts.md#c03)，以及由[給定](concepts.md#c03)推出的東西。**

---

## 一、原語

- **[時刻](concepts.md#c04)**：時間的索引。[時刻](concepts.md#c04)以正整數編號：[初始時刻](concepts.md#c05)是第一個，每個[時刻](concepts.md#c04)的[後繼](concepts.md#c06)是編號加一的那個[時刻](concepts.md#c04)；每個[時刻](concepts.md#c04)都有編號。
- **[刺激](concepts.md#c07)**：每個[時刻](concepts.md#c04)隨之[出現](concepts.md#c08)的物理內容。光、聲音、重力波、熱輻射等。哪個[刺激](concepts.md#c07)在哪個[時刻](concepts.md#c04)[出現](concepts.md#c08)，隨[刺激](concepts.md#c07)一起[給定](concepts.md#c03)：

```text
出現 ⊆ 刺激 × 時刻
```

---

## 二、公設

以下三條不可推出，只能承認。

### 公設一：初始信

```text
|全域態(初始時刻)⟩ = |初始信⟩ ∈ 記錄空間,   ‖初始信‖ = 1
```

[初始信](concepts.md#c09)是單位向量。它來自[奇點](concepts.md#c01)，不追問。

[初始時刻](concepts.md#c05)的[記錄](concepts.md#c17)由本公設[給定](concepts.md#c03)，不經[寫入](concepts.md#c21)；[初始時刻](concepts.md#c05)的[刺激束](concepts.md#c27)不[寫入](concepts.md#c21)任何[記錄](concepts.md#c17)。[寫入](concepts.md#c21)只發生在每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)。

### 公設二：切分

```text
信空間(初始時刻) = 記錄空間
環境總空間(初始時刻) = 空乘積        // 初始時刻沒有環境
信空間(下一時刻) = 信空間(時刻) ⊗ 記錄空間
環境總空間(下一時刻) = 環境總空間(時刻) ⊗ 環境空間
宇宙空間(時刻) = 信空間(時刻) ⊗ 環境總空間(時刻)
記錄空間 的基底給定
```

[切分](concepts.md#c10)把宇宙切成兩部分：保留的[累積](concepts.md#c30)（[信](concepts.md#c26)）與被積掉的其餘（[環境](concepts.md#c11)）。[宇宙空間](concepts.md#c12)因此由[信空間](concepts.md#c13)與[環境總空間](concepts.md#c14)組成：[信空間](concepts.md#c13)是[信](concepts.md#c26)所在的空間，由一份份[記錄空間](concepts.md#c15)排成；[環境總空間](concepts.md#c14)是[環境](concepts.md#c11)所在的空間，由一份份[環境空間](concepts.md#c16)排成，隨[時刻](concepts.md#c04)增長。[信](concepts.md#c26)由一筆筆[記錄](concepts.md#c17)排成，而[記錄](concepts.md#c17)以什麼[基底](concepts.md#c18)讀出，是[給定](concepts.md#c03)的。「序列」之所以是序列，是因為這條公設。

每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)，[信](concepts.md#c26)多一筆[記錄](concepts.md#c17)，[環境](concepts.md#c11)多一份。[初始時刻](concepts.md#c05)只有[初始信](concepts.md#c09)，沒有[環境](concepts.md#c11)。

[刺激](concepts.md#c07)不是宇宙的持存部分。[刺激](concepts.md#c07)是每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)新[出現](concepts.md#c08)的自由度，[出現](concepts.md#c08)即被[寫入](concepts.md#c21)（公設三）。

**[切分](concepts.md#c10)不是觀察。** [切分](concepts.md#c10)只劃線，不選結果。

### 公設三：寫入

```text
刺激空間 與 環境空間 給定
編碼 : 刺激束 → 刺激空間 中的單位向量,   編碼(∅) = |∅⟩
給定一個固定的等距映射  寫入映射 : 刺激空間 → 記錄空間 ⊗ 環境空間
    （故 維度 刺激空間 ≤ 維度 記錄空間 · 維度 環境空間）
寫入映射 對所有後繼相同
```

[編碼](concepts.md#c19)對每個[刺激束](concepts.md#c27)都給定[刺激空間](concepts.md#c20)中的一個值，包括含多個[刺激](concepts.md#c07)的[刺激束](concepts.md#c27)；具體的值不指定。

這條公設規定一個[刺激](concepts.md#c07)如何被[寫成](concepts.md#c21)一筆[記錄](concepts.md#c17)。[寫入映射](concepts.md#c22)只碰新[出現](concepts.md#c08)的[刺激](concepts.md#c07)，從不碰已經存在的東西。

[空刺激束](concepts.md#c23)對應[真空態](concepts.md#c24)：一個真實的態，不是零向量。[寫入映射](concepts.md#c22)從哪裡來，[形式層](concepts.md#c02)不知道。

## 三、定義

### 定義一：全域態

```text
|全域態(下一時刻)⟩ = ( 恆等_過去 ⊗ 寫入映射 ) ( |全域態(時刻)⟩ ⊗ 編碼(刺激束(下一時刻)) )

其中 恆等_過去 作用於 宇宙空間(時刻)
結果住在 宇宙空間(下一時刻)
```

[全域態](concepts.md#c25)即宇宙在該[時刻](concepts.md#c04)的態。它只經歷[寫入](concepts.md#c21)。舊的不動，新的接在後面。

### 定義二：信

```text
信(時刻) = 跡_環境 |全域態(時刻)⟩⟨全域態(時刻)|
```

[信](concepts.md#c26)是[全域態](concepts.md#c25)在[切分](concepts.md#c10)之下的約化態，對全部[環境](concepts.md#c11)取偏跡。沒有「誰的[信](concepts.md#c26)」。[信](concepts.md#c26)是[累積](concepts.md#c30)本身，沒有主體。

### 定義三：刺激束

```text
刺激束(時刻) = {刺激 ∈ 刺激 | 出現(刺激, 時刻)}
```

在每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)，[刺激束](concepts.md#c27)為空集時，該[時刻](concepts.md#c04)仍[寫下](concepts.md#c21)一筆由[真空態](concepts.md#c24)產生的[記錄](concepts.md#c17)。[空記錄](concepts.md#c28)不是零筆[記錄](concepts.md#c17)。

## 四、推論

以下兩條皆可從公設與定義推出。

### 推論一：累積

```text
對所有後繼 [
  信空間(下一時刻) = 信空間(時刻) ⊗ 記錄空間        // 多一筆記錄
  且 跡_最新記錄 信(下一時刻) = 信(時刻)
]
```

**證明。** 由公設二，[信空間](concepts.md#c13)([下一時刻](concepts.md#c06)) = [信空間](concepts.md#c13)([時刻](concepts.md#c04)) ⊗ [記錄空間](concepts.md#c15)：[信](concepts.md#c26)多一筆[記錄](concepts.md#c17)。

記 |新刺激態⟩ = [編碼](concepts.md#c19)([刺激束](concepts.md#c27)([下一時刻](concepts.md#c06)))。由定義一：

```text
|全域態(下一時刻)⟩ = |全域態(時刻)⟩ ⊗ 寫入映射|新刺激態⟩
```

新舊兩部分為乘積。張量因子依標準同構重排，[記錄](concepts.md#c17)在前、[環境](concepts.md#c11)在後。由定義二：

```text
信(下一時刻) = 信(時刻) ⊗ 跡_新環境( 寫入映射|新刺激態⟩⟨新刺激態|寫入映射† )
```

對[最新記錄](concepts.md#c29)取跡：

```text
跡_最新記錄 信(下一時刻) = 信(時刻) · 跡( 寫入映射|新刺激態⟩⟨新刺激態|寫入映射† )
                         = 信(時刻) · ⟨新刺激態|寫入映射†寫入映射|新刺激態⟩
                         = 信(時刻)
```

最後一步用到[寫入映射](concepts.md#c22)為等距映射（[寫入映射](concepts.md#c22)†[寫入映射](concepts.md#c22) = 恆等）與 |新刺激態⟩ 為單位向量。∎

這就是[累積](concepts.md#c30)：每個[時刻](concepts.md#c04)多一筆[記錄](concepts.md#c17)，過去不被改寫。[信](concepts.md#c26)的改變不是覆蓋，是增長。

### 推論二：非坍縮

```text
演化規則：定義一給出的映射  |全域態(時刻)⟩ ↦ |全域態(下一時刻)⟩
選出：某時刻的態送到下一時刻之態的映射不是等距映射

對所有後繼：形式層中的全域態未經歷選出
```

**證明。** 記 |新刺激態⟩ = [編碼](concepts.md#c19)([刺激束](concepts.md#c27)([下一時刻](concepts.md#c06)))。由定義一，[演化規則](concepts.md#c31)是兩步的合成：

```text
演化規則 = ( 恆等_過去 ⊗ 寫入映射 ) ∘ 接上映射,     接上映射 |態⟩ = |態⟩ ⊗ |新刺激態⟩
```

接上映射是等距映射：對任意 |態一⟩、|態二⟩，⟨態一 ⊗ 新刺激態 | 態二 ⊗ 新刺激態⟩ = ⟨態一|態二⟩ · ⟨新刺激態|新刺激態⟩ = ⟨態一|態二⟩。恆等_過去 ⊗ [寫入映射](concepts.md#c22)是等距映射，因為 恆等_過去 與[寫入映射](concepts.md#c22)皆是。等距映射的合成是等距映射，故[演化規則](concepts.md#c31)是等距映射。[形式層](concepts.md#c02)中的[全域態](concepts.md#c25)未經歷[選出](concepts.md#c32)。∎

[信](concepts.md#c26)可以在[記錄基底](concepts.md#c18)下是對角的，看起來像經典序列的機率分布。[非坍縮](concepts.md#c33)不否認這一點，它否認的是**[選出](concepts.md#c32)**。對角不是坍縮。看起來經典，不等於已經是某一條。

---

## 五、觀察者問題

[形式層](concepts.md#c02)有[切分](concepts.md#c10)，但沒有觀察者。

[切分](concepts.md#c10)劃出[信](concepts.md#c26)與[環境](concepts.md#c11)的界線，不選結果。[形式層](concepts.md#c02)的[全域態](concepts.md#c25)演化不包含[選出](concepts.md#c32)（推論二）。

---

## 六、結論

這個宇宙只增不改。沒有什麼在運動，沒有什麼被改變，只有[記錄](concepts.md#c17)一筆一筆地[累積](concepts.md#c30)。[時刻](concepts.md#c04)與[記錄](concepts.md#c17)的筆數一一對應。

## 附錄：非退化模型（前三個時刻）

以下是一個[非退化模型](concepts.md#c34)：兩個[刺激](concepts.md#c07)，[刺激甲](concepts.md#c35)與[刺激乙](concepts.md#c36)，給出[初始時刻](concepts.md#c05)、[第二時刻](concepts.md#c37)、[第三時刻](concepts.md#c38)的完整資料。

```text
前三個時刻 = 初始時刻, 第二時刻, 第三時刻      // 後續時刻依同一寫入延伸
刺激 = {刺激甲, 刺激乙}

記錄空間 = 張成{|0⟩, |1⟩}
刺激空間 = 張成{|∅⟩, |甲⟩, |乙⟩}
環境空間 = 張成{|0⟩, |1⟩}

出現(刺激乙, 第二時刻) = 真
出現(刺激甲, 第三時刻) = 真
// 前三個時刻內，其餘的出現皆為假

|初始信⟩ = |0⟩

編碼({刺激甲}) = |甲⟩
編碼({刺激乙}) = |乙⟩
// 編碼(∅) = |∅⟩ 由公設三給定
// {刺激甲, 刺激乙} 在前三個時刻不出現，其編碼可任取單位向量

寫入映射|∅⟩ = |0⟩_記錄 |1⟩_環境
寫入映射|甲⟩ = ( |0⟩_記錄 |0⟩_環境 + |1⟩_記錄 |1⟩_環境 ) / √2
寫入映射|乙⟩ = |1⟩_記錄 |0⟩_環境
```

**計算：**

```text
信(初始時刻) = |0⟩⟨0|
信(第二時刻) = |0⟩⟨0| ⊗ |1⟩⟨1|
信(第三時刻) = |0⟩⟨0| ⊗ |1⟩⟨1| ⊗ (恆等/2)
```

**檢核：**

- [寫入映射](concepts.md#c22)為等距映射：三個像兩兩正交，範數為一 ✓
- 推論一：[記錄](concepts.md#c17)筆數 1 → 2 → 3 ✓。過去[記錄](concepts.md#c17)不變 ✓
- 推論二：每一步的[演化規則](concepts.md#c31)為等距映射 ✓。[信](concepts.md#c26)([第三時刻](concepts.md#c38)) [最新記錄](concepts.md#c29)為 恆等/2，在[記錄基底](concepts.md#c18)下對角，但沒有任何分支被[選出](concepts.md#c32) ✓
- [空刺激束](concepts.md#c23)、[刺激甲](concepts.md#c35)、[刺激乙](concepts.md#c36)三者產生的[記錄](concepts.md#c17)兩兩不同 ✓

**這個宇宙沒有人。沒有觀察者。只有[時刻](concepts.md#c04)、[刺激](concepts.md#c07)、[信](concepts.md#c26)。**
