# 暗宇宙的本體論

## 框架宣告<!--句2413228854-->

[奇點](concepts.md#c01)沒有[時刻](concepts.md#c04)。<!--句2804322673-->

[時刻](concepts.md#c04)從[奇點](concepts.md#c01)之後開始。<!--句5865042996-->[奇點](concepts.md#c01)沒有之前。<!--句1466615897-->[奇點](concepts.md#c01)不可被形式化。<!--句4724837907-->

本框架描述的是：[時刻](concepts.md#c04)已經開始，[刺激](concepts.md#c07)已經[出現](concepts.md#c08)，[信](concepts.md#c26)已經[累積](concepts.md#c30)，沒有觀察者的宇宙。<!--句2267107740-->這個宇宙，就是[形式層](concepts.md#c02)。<!--句1303658764-->

[形式層](concepts.md#c02)沒有觀察者，但有[給定](concepts.md#c03)。<!--句6303127914-->[給定](concepts.md#c03)是[形式層](concepts.md#c02)無法自己產生的東西。<!--句2552416451-->本框架的原則是：**不可推出的東西，越少越好；凡不可推出的，一律明列。<!--句6828290729-->[形式層](concepts.md#c02)中只有明列的[給定](concepts.md#c03)，以及由[給定](concepts.md#c03)推出的東西。**<!--句0068040101-->

---

## 一、原語<!--句2370936929-->

- **[時刻](concepts.md#c04)**：時間的索引。<!--句1944056660-->[時刻](concepts.md#c04)以正整數編號：[初始時刻](concepts.md#c05)是第一個，每個[時刻](concepts.md#c04)的[後繼](concepts.md#c06)是編號加一的那個[時刻](concepts.md#c04)；每個[時刻](concepts.md#c04)都有編號。<!--句3474880125-->
- **[刺激](concepts.md#c07)**：每個[時刻](concepts.md#c04)隨之[出現](concepts.md#c08)的物理內容。<!--句7817603396-->光、聲音、重力波、熱輻射等。<!--句8624119582-->哪個[刺激](concepts.md#c07)在哪個[時刻](concepts.md#c04)[出現](concepts.md#c08)，隨[刺激](concepts.md#c07)一起[給定](concepts.md#c03)：<!--句3088693906-->

```text
出現 ⊆ 刺激 × 時刻
```
<!--句3607368803-->

## 二、公設<!--句0967505617-->

以下三條不可推出，只能承認。<!--句7557647677-->

### 公設一：初始信<!--句1351552101-->

```text
|全域態(初始時刻)⟩ = |初始信⟩ ∈ 記錄空間,   ‖初始信‖ = 1
```
<!--句0796979366-->

[初始信](concepts.md#c09)是單位向量。<!--句4306012983-->它來自[奇點](concepts.md#c01)，不追問。<!--句6131400324-->

[初始時刻](concepts.md#c05)的[記錄](concepts.md#c17)由本公設[給定](concepts.md#c03)，不經[寫入](concepts.md#c21)；[初始時刻](concepts.md#c05)的[刺激束](concepts.md#c27)不[寫入](concepts.md#c21)任何[記錄](concepts.md#c17)。<!--句3813014508-->[寫入](concepts.md#c21)只發生在每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)。<!--句4463596426-->

### 公設二：切分<!--句4527977637-->

```text
信空間(初始時刻) = 記錄空間
環境總空間(初始時刻) = 空乘積        // 初始時刻沒有環境
信空間(下一時刻) = 信空間(時刻) ⊗ 記錄空間
環境總空間(下一時刻) = 環境總空間(時刻) ⊗ 環境空間
宇宙空間(時刻) = 信空間(時刻) ⊗ 環境總空間(時刻)
記錄空間 的基底給定
```
<!--句0050409113-->

[切分](concepts.md#c10)把宇宙切成兩部分：保留的[累積](concepts.md#c30)（[信](concepts.md#c26)）與被積掉的其餘（[環境](concepts.md#c11)）。<!--句1065936577-->[宇宙空間](concepts.md#c12)因此由[信空間](concepts.md#c13)與[環境總空間](concepts.md#c14)組成：[信空間](concepts.md#c13)是[信](concepts.md#c26)所在的空間，由一份份[記錄空間](concepts.md#c15)排成；[環境總空間](concepts.md#c14)是[環境](concepts.md#c11)所在的空間，由一份份[環境空間](concepts.md#c16)排成，隨[時刻](concepts.md#c04)增長。<!--句6021879499-->[信](concepts.md#c26)由一筆筆[記錄](concepts.md#c17)排成，而[記錄](concepts.md#c17)以什麼[基底](concepts.md#c18)讀出，是[給定](concepts.md#c03)的。<!--句1810474327-->「序列」之所以是序列，是因為這條公設。<!--句2343287469-->

每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)，[信](concepts.md#c26)多一筆[記錄](concepts.md#c17)，[環境](concepts.md#c11)多一份。<!--句8967661511-->[初始時刻](concepts.md#c05)只有[初始信](concepts.md#c09)，沒有[環境](concepts.md#c11)。<!--句0702858968-->

[刺激](concepts.md#c07)不是宇宙的持存部分。<!--句4433144146-->[刺激](concepts.md#c07)是每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)新[出現](concepts.md#c08)的自由度，[出現](concepts.md#c08)即被[寫入](concepts.md#c21)（公設三）。<!--句7033196608-->

**[切分](concepts.md#c10)不是觀察。**<!--句8340190777--> [切分](concepts.md#c10)只劃線，不選結果。<!--句6350659705-->

### 公設三：寫入<!--句4589420741-->

```text
刺激空間 與 環境空間 給定
編碼 : 刺激束 → 刺激空間 中的單位向量,   編碼(∅) = |∅⟩
給定一個固定的等距映射  寫入映射 : 刺激空間 → 記錄空間 ⊗ 環境空間
    （故 維度 刺激空間 ≤ 維度 記錄空間 · 維度 環境空間）
寫入映射 對所有後繼相同
```
<!--句3399753925-->

[編碼](concepts.md#c19)對每個[刺激束](concepts.md#c27)都給定[刺激空間](concepts.md#c20)中的一個值，包括含多個[刺激](concepts.md#c07)的[刺激束](concepts.md#c27)；具體的值不指定。<!--句3026819045-->

這條公設規定一個[刺激](concepts.md#c07)如何被[寫成](concepts.md#c21)一筆[記錄](concepts.md#c17)。<!--句3894285170-->[寫入映射](concepts.md#c22)只碰新[出現](concepts.md#c08)的[刺激](concepts.md#c07)，從不碰已經存在的東西。<!--句4473185142-->

[空刺激束](concepts.md#c23)對應[真空態](concepts.md#c24)：一個真實的態，不是零向量。<!--句8748484015-->[寫入映射](concepts.md#c22)從哪裡來，[形式層](concepts.md#c02)不知道。<!--句1978615298-->

## 三、定義<!--句5990676167-->

### 定義一：全域態<!--句2345190277-->

```text
|全域態(下一時刻)⟩ = ( 恆等_過去 ⊗ 寫入映射 ) ( |全域態(時刻)⟩ ⊗ 編碼(刺激束(下一時刻)) )

其中 恆等_過去 作用於 宇宙空間(時刻)
結果住在 宇宙空間(下一時刻)
```
<!--句4546989263-->

[全域態](concepts.md#c25)即宇宙在該[時刻](concepts.md#c04)的態。<!--句2981870074-->它只經歷[寫入](concepts.md#c21)。<!--句2257760632-->舊的不動，新的接在後面。<!--句0712631184-->

### 定義二：信<!--句8311539837-->

```text
信(時刻) = 跡_環境 |全域態(時刻)⟩⟨全域態(時刻)|
```
<!--句4315146058-->

[信](concepts.md#c26)是[全域態](concepts.md#c25)在[切分](concepts.md#c10)之下的約化態，對全部[環境](concepts.md#c11)取偏跡。<!--句6609604575-->沒有「誰的[信](concepts.md#c26)」。<!--句3019030014-->[信](concepts.md#c26)是[累積](concepts.md#c30)本身，沒有主體。<!--句4809905115-->

### 定義三：刺激束<!--句9457326661-->

```text
刺激束(時刻) = {刺激 ∈ 刺激 | 出現(刺激, 時刻)}
```
<!--句9996010962-->

在每個[後繼](concepts.md#c06)[時刻](concepts.md#c04)，[刺激束](concepts.md#c27)為空集時，該[時刻](concepts.md#c04)仍[寫下](concepts.md#c21)一筆由[真空態](concepts.md#c24)產生的[記錄](concepts.md#c17)。<!--句5049795615-->[空記錄](concepts.md#c28)不是零筆[記錄](concepts.md#c17)。<!--句7003000354-->

## 四、推論<!--句8029749710-->

以下兩條皆可從公設與定義推出。<!--句4859045216-->

### 推論一：累積<!--句8298861916-->

```text
對所有後繼 [
  信空間(下一時刻) = 信空間(時刻) ⊗ 記錄空間        // 多一筆記錄
  且 跡_最新記錄 信(下一時刻) = 信(時刻)
]
```
<!--句4297742926-->

**證明。**<!--句2085578999--> 由公設二，[信空間](concepts.md#c13)([下一時刻](concepts.md#c06)) = [信空間](concepts.md#c13)([時刻](concepts.md#c04)) ⊗ [記錄空間](concepts.md#c15)：[信](concepts.md#c26)多一筆[記錄](concepts.md#c17)。<!--句6925276349-->

記 |新刺激態⟩ = [編碼](concepts.md#c19)([刺激束](concepts.md#c27)([下一時刻](concepts.md#c06)))。<!--句9037195502-->由定義一：<!--句9109178138-->

```text
|全域態(下一時刻)⟩ = |全域態(時刻)⟩ ⊗ 寫入映射|新刺激態⟩
```
<!--句0836910715-->

新舊兩部分為乘積。<!--句9038133932-->張量因子依標準同構重排，[記錄](concepts.md#c17)在前、[環境](concepts.md#c11)在後。<!--句5919236813-->由定義二：<!--句9226613099-->

```text
信(下一時刻) = 信(時刻) ⊗ 跡_新環境( 寫入映射|新刺激態⟩⟨新刺激態|寫入映射† )
```
<!--句3034772101-->

對[最新記錄](concepts.md#c29)取跡：<!--句4818443210-->

```text
跡_最新記錄 信(下一時刻) = 信(時刻) · 跡( 寫入映射|新刺激態⟩⟨新刺激態|寫入映射† )
                         = 信(時刻) · ⟨新刺激態|寫入映射†寫入映射|新刺激態⟩
                         = 信(時刻)
```
<!--句5193699410-->

最後一步用到[寫入映射](concepts.md#c22)為等距映射（[寫入映射](concepts.md#c22)†[寫入映射](concepts.md#c22) = 恆等）與 |新刺激態⟩ 為單位向量。<!--句7241307993-->∎

這就是[累積](concepts.md#c30)：每個[時刻](concepts.md#c04)多一筆[記錄](concepts.md#c17)，過去不被改寫。<!--句3021229940-->[信](concepts.md#c26)的改變不是覆蓋，是增長。<!--句4435744503-->

### 推論二：非坍縮<!--句0098448602-->

```text
演化規則：定義一給出的映射  |全域態(時刻)⟩ ↦ |全域態(下一時刻)⟩
選出：某時刻的態送到下一時刻之態的映射不是等距映射

對所有後繼：形式層中的全域態未經歷選出
```
<!--句0555701433-->

**證明。**<!--句2085578999--> 記 |新刺激態⟩ = [編碼](concepts.md#c19)([刺激束](concepts.md#c27)([下一時刻](concepts.md#c06)))。<!--句9037195502-->由定義一，[演化規則](concepts.md#c31)是兩步的合成：<!--句4145541989-->

```text
演化規則 = ( 恆等_過去 ⊗ 寫入映射 ) ∘ 接上映射,     接上映射 |態⟩ = |態⟩ ⊗ |新刺激態⟩
```
<!--句3962360953-->

接上映射是等距映射：對任意 |態一⟩、|態二⟩，⟨態一 ⊗ 新刺激態 | 態二 ⊗ 新刺激態⟩ = ⟨態一|態二⟩ · ⟨新刺激態|新刺激態⟩ = ⟨態一|態二⟩。<!--句1117132721-->恆等_過去 ⊗ [寫入映射](concepts.md#c22)是等距映射，因為 恆等_過去 與[寫入映射](concepts.md#c22)皆是。<!--句4320733487-->等距映射的合成是等距映射，故[演化規則](concepts.md#c31)是等距映射。<!--句6153435550-->[形式層](concepts.md#c02)中的[全域態](concepts.md#c25)未經歷[選出](concepts.md#c32)。<!--句9519889273-->∎

[信](concepts.md#c26)可以在[記錄基底](concepts.md#c18)下是對角的，看起來像經典序列的機率分布。<!--句4642780187-->[非坍縮](concepts.md#c33)不否認這一點，它否認的是**[選出](concepts.md#c32)**。<!--句9833262297-->對角不是坍縮。<!--句3830646985-->看起來經典，不等於已經是某一條。<!--句5078677783-->

## 五、觀察者問題<!--句6585476963-->

[形式層](concepts.md#c02)有[切分](concepts.md#c10)，但沒有觀察者。<!--句1075202277-->

[切分](concepts.md#c10)劃出[信](concepts.md#c26)與[環境](concepts.md#c11)的界線，不選結果。<!--句6385972097-->[形式層](concepts.md#c02)的[全域態](concepts.md#c25)演化不包含[選出](concepts.md#c32)（推論二）。<!--句2242920401-->

## 六、結論<!--句6790580218-->

這個宇宙只增不改。<!--句2994773955-->沒有什麼在運動，沒有什麼被改變，只有[記錄](concepts.md#c17)一筆一筆地[累積](concepts.md#c30)。<!--句6183972241-->[時刻](concepts.md#c04)與[記錄](concepts.md#c17)的筆數一一對應。<!--句8400308605-->

## 附錄：非退化模型（前三個時刻）<!--句8774282582-->

以下是一個[非退化模型](concepts.md#c34)：兩個[刺激](concepts.md#c07)，[刺激甲](concepts.md#c35)與[刺激乙](concepts.md#c36)，給出[初始時刻](concepts.md#c05)、[第二時刻](concepts.md#c37)、[第三時刻](concepts.md#c38)的完整資料。<!--句8295366179-->

```text
前三個時刻 = 初始時刻, 第二時刻, 第三時刻      // 後續時刻依同一寫入延伸
刺激 = {刺激甲, 刺激乙}

記錄空間 = 張成{|0⟩, |1⟩}
刺激空間 = 張成{|∅⟩, |甲⟩, |乙⟩}
環境空間 = 張成{|0⟩, |1⟩}

出現(刺激乙, 第二時刻) = 真
出現(刺激甲, 第三時刻) = 真
// 前三個時刻內，其餘的出現皆為假

|初始信⟩ = |0⟩

編碼({刺激甲}) = |甲⟩
編碼({刺激乙}) = |乙⟩
// 編碼(∅) = |∅⟩ 由公設三給定
// {刺激甲, 刺激乙} 在前三個時刻不出現，其編碼可任取單位向量

寫入映射|∅⟩ = |0⟩_記錄 |1⟩_環境
寫入映射|甲⟩ = ( |0⟩_記錄 |0⟩_環境 + |1⟩_記錄 |1⟩_環境 ) / √2
寫入映射|乙⟩ = |1⟩_記錄 |0⟩_環境
```
<!--句9153070184-->

**計算：**<!--句0357757296-->

```text
信(初始時刻) = |0⟩⟨0|
信(第二時刻) = |0⟩⟨0| ⊗ |1⟩⟨1|
信(第三時刻) = |0⟩⟨0| ⊗ |1⟩⟨1| ⊗ (恆等/2)
```
<!--句8036516582-->

**檢核：**<!--句5189961911-->

- [寫入映射](concepts.md#c22)為等距映射：三個像兩兩正交，範數為一 ✓<!--句1290319221-->
- 推論一：[記錄](concepts.md#c17)筆數 1 → 2 → 3 ✓。<!--句9405668440-->過去[記錄](concepts.md#c17)不變 ✓<!--句1712782291-->
- 推論二：每一步的[演化規則](concepts.md#c31)為等距映射 ✓。<!--句6780078199-->[信](concepts.md#c26)([第三時刻](concepts.md#c38)) [最新記錄](concepts.md#c29)為 恆等/2，在[記錄基底](concepts.md#c18)下對角，但沒有任何分支被[選出](concepts.md#c32) ✓<!--句6050305013-->
- [空刺激束](concepts.md#c23)、[刺激甲](concepts.md#c35)、[刺激乙](concepts.md#c36)三者產生的[記錄](concepts.md#c17)兩兩不同 ✓<!--句4586639499-->

**這個宇宙沒有人。<!--句5856831247-->沒有觀察者。<!--句4166546020-->只有[時刻](concepts.md#c04)、[刺激](concepts.md#c07)、[信](concepts.md#c26)。**<!--句0914284229-->
