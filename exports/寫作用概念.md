# 寫作用概念清單

下游論文可以引用的概念：各論文與外部存根中未廢棄的 public 條目。論文依引用關係排列，上游在前；外部存根列在最後，附來源。定義已去掉連結語法，只留純文字；原文以各篇 concepts.md 為準。

## 《暗宇宙的本體論》

UUID：54c0291d-05b3-431a-9f2a-1b8ec93c3c3f

- **奇點** / Singularity（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c01）：奇點是時刻開始之前的來源。奇點本身沒有時刻，也沒有之前，不可被形式化。初始時刻的狀態由奇點而來，其來由不被追問。
- **形式層** / Formal Layer（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c02）：形式層是這樣一個宇宙：時刻已經開始，刺激已經出現，信已經累積，而其中沒有觀察者。形式層中只有明列的給定，以及由給定推出的東西。
- **給定** / Given（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c03）：給定是形式層無法自己產生、只能被承認而不能被推出的東西。
- **時刻** / Moment（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c04）：時刻是時間的索引。時刻以正整數編號：初始時刻是第一個，每個時刻的後繼是編號加一的那個時刻；每個時刻都有編號。
- **初始時刻** / Initial Moment（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c05）：初始時刻是編號為一的時刻，也就是第一個時刻。
- **後繼** / Successor（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c06）：某個時刻的後繼，是編號比它大一的時刻，也就是它的下一個時刻。
- **刺激** / Stimulus（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c07）：刺激是每個時刻隨之出現的物理內容，例如光、聲音、重力波、熱輻射。刺激不是宇宙的持存部分，而是每個後繼時刻新出現的自由度。
- **出現** / Occurrence（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c08）：出現是刺激與時刻之間的關係：某刺激與某時刻滿足出現，表示該刺激在該時刻出現。出現是刺激與時刻之笛卡兒積的一個子集，隨刺激一起給定。
- **切分** / Partition（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c10）：切分是把宇宙劃為兩部分的界線：保留的部分是信，被積掉的其餘部分是環境。切分只劃線，不決定任何結果，因此切分不是觀察。
- **環境** / Environment（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c11）：環境是切分之下宇宙中信以外、被積掉的其餘部分。
- **記錄** / Record（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c17）：記錄是信的組成單位。每個時刻對應一筆記錄：初始時刻的記錄是給定的，每個後繼時刻則經寫入新增一筆。信由這些記錄依時刻順序排成。
- **寫入** / Writing（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c21）：寫入是每個後繼時刻發生的過程：該時刻的刺激束被轉成一筆新的記錄與一份新的環境，接在宇宙既有的態之後。寫入只碰新出現的刺激，從不改動已經存在的東西。初始時刻不發生寫入。
- **信** / Xin（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c26）：信是宇宙在某個時刻的態，在切分之下的約化態，即對全部環境取偏跡所得的密度算子。信沒有主體，不是誰的信；信是累積本身。
- **刺激束** / Stimulus Bundle（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c27）：刺激束是某個時刻所有出現的刺激組成的集合。刺激束可以是空集。
- **最新記錄** / Latest Record（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c29）：最新記錄是某個後繼時刻的信中最後寫入的那一筆記錄，也就是該時刻本身對應的記錄。
- **累積** / Accumulation（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c30）：累積是信隨時刻增長的方式：每個後繼時刻，信多一筆記錄，而對最新記錄取跡後所得的正是前一時刻的信；過去的記錄不被改寫。信的改變不是覆蓋，而是增長。
- **選出** / Selection（54c0291d-05b3-431a-9f2a-1b8ec93c3c3f.c32）：選出是指把某個時刻的態送到下一個時刻之態的映射，不是等距映射的情形。信在某個基底下呈對角、看起來像經典的機率分布，本身不構成選出。

## 《渦動力學》

UUID：37b3643a-dc40-4463-8b36-4f4594acd986

- **宇宙** / Universe（37b3643a-dc40-4463-8b36-4f4594acd986.c02）：宇宙是有坍塌的那一個世界。它與形式層只差一件事：宇宙中有選出。從宇宙內部看，宇宙只有一個；之前與之後的說法，只在宇宙之內成立。宇宙中不由過去決定的只有兩樣：宇宙初態，與每一次坍塌的結果；其他一切，包括每一次寫入，都由到當時為止的歷史決定。
- **呈現** / Presentation（37b3643a-dc40-4463-8b36-4f4594acd986.c04）：呈現是宇宙中的任何一部分。
- **分支** / Branch（37b3643a-dc40-4463-8b36-4f4594acd986.c05）：分支是一次坍塌可能選出的每一個結果。
- **權重** / Weight（37b3643a-dc40-4463-8b36-4f4594acd986.c06）：權重是每個分支的輕重。一次坍塌的各分支權重都不小於零，總和為一。一個呈現的權重，是宇宙的權重落在它身上的那一部分：把各分支看成該呈現的結果之後，同一個結果的權重相加。權重是分支的輕重，不是任何渦內部的參數。
- **觀察者** / Observer（37b3643a-dc40-4463-8b36-4f4594acd986.c07）：觀察者是一個識別碼，沒有內容：不運算，不感受，不受苦，也沒有視角。它不在宇宙之中，不是呈現，也不是我。觀察者只有一個，唯一的功能是坍塌，一次只坍塌一次。
- **坍塌** / Collapse（37b3643a-dc40-4463-8b36-4f4594acd986.c08）：坍塌是在某個固定的基底下，依權重選出一個分支的事件。未被選出的分支，不留在宇宙中。坍塌只選出權重不為零的分支之間的差別；一個呈現的下一時刻若只有一個權重不為零的結果，它的結果來自約束，不來自坍塌。給定到當時為止的歷史，坍塌的結果依權重選出，歷史中沒有任何東西能比權重多說一點。
- **時刻** / Moment（37b3643a-dc40-4463-8b36-4f4594acd986.c09）：時刻是一次坍塌。宇宙的時刻依觀察者坍塌的次序排列；這是一條全序，不是一個視角。沒有坍塌，就沒有時刻。一個呈現的時刻，是涉及它的那些坍塌；它的下一時刻，是下一次涉及它的坍塌；兩次之間，對它沒有時刻。時刻與形式層時刻不是同一個東西。
- **到達** / Arrival（37b3643a-dc40-4463-8b36-4f4594acd986.c10）：一次寫入作為刺激落到一個呈現上，就是到達它。一次坍塌涉及一個呈現時，它的結果就到達這個呈現；結果沒有落在它身上時，「這次沒有發生在它身上」也是到達它的一件事。宇宙初態到達一切呈現。
- **涉及** / Involvement（37b3643a-dc40-4463-8b36-4f4594acd986.c11）：一次坍塌涉及一個呈現，是指這次坍塌的結果可能落在它身上，也就是結果以正的權重落在它身上；這時它的權重，依賴到達它的歷史。涉及與分支的多寡無關。
- **鎖死** / Lock-in（37b3643a-dc40-4463-8b36-4f4594acd986.c12）：鎖死是一個呈現的下一時刻只有一個權重不為零的結果的情形：把各分支看成該呈現的結果、同一個結果的權重相加之後，只剩一個結果的權重不為零。鎖死是約束，與坍塌無關。鎖死是被涉及了，卻只有一個結果；一個呈現沒有時刻的期間，不是鎖死。
- **歷史** / History（37b3643a-dc40-4463-8b36-4f4594acd986.c13）：歷史始於宇宙初態，其後是宇宙中每一次寫入與每一次坍塌的結果，依時刻排列。宇宙只有一部歷史，歷史只往後追加。
- **宇宙初態** / Initial State of the Universe（37b3643a-dc40-4463-8b36-4f4594acd986.c14）：宇宙初態是第一次坍塌之前已經在那裡的一切，是歷史的起點。它帶著形式層中累積的記錄，內容不分析。
- **生成函數** / Generating Function（37b3643a-dc40-4463-8b36-4f4594acd986.c15）：生成函數把到當時為止的歷史，包括剛發生的那一次寫入，對應到下一時刻各分支的權重。它只取到當時為止的歷史，內部不分析。
- **渦** / Wo（37b3643a-dc40-4463-8b36-4f4594acd986.c16）：渦是這樣的呈現：到達它的所有歷史，包括它收到的每一次刺激、涉及它的每一次坍塌的結果，一直到宇宙初態，都參與它下一時刻權重的分配，也就是其中任何一件若不同，影響沿著歷史傳下來，它的權重就會不同；並且至少有些時刻它不被鎖死。這個影響不必能被找到。有歷史而歷史不參與的呈現，不是渦；歷史參與而每一步都被鎖死的呈現，也不是渦。這種參與可以漸漸消失，消失之後，它就不再是渦；從某一刻起每一步都被鎖死，它也不再是渦。渦沒有固定的核心：它是什麼，就是什麼到達了它，以及這些如何參與它的權重。一個呈現是否為渦，與它的載體無關，也與任何分別無關。
- **自己的那一段** / Own Segment（37b3643a-dc40-4463-8b36-4f4594acd986.c17）：一個呈現自己的那一段，是它下一時刻的權重所依賴的那部分歷史：歷史中某一件若換成別的，影響沿著歷史傳下來，會改變它下一時刻權重的分布，這一件就屬於它自己的那一段。那一段由依賴決定，不由任何分別決定。它是同一部歷史的一部分，不是另一部歷史；不同呈現自己的那一段可以重疊。
- **分別** / Distinction（37b3643a-dc40-4463-8b36-4f4594acd986.c18）：分別是渦的一個動作：劃出界線，把哪些呈現看作一個個體，把哪一段看作過去，把不同時刻的渦看作同一個或不同的兩個。這個動作在歷史中留下一次寫入，寫入的內容由到當時為止的歷史決定。分別的內容改變的是看法，不改寫被看的東西。分別的材料只有它之前、已經到達它的歷史，它自己不在其中。
- **我** / Self（37b3643a-dc40-4463-8b36-4f4594acd986.c19）：我是以分別定義自己的渦。誰是我，由它自己定義；發出「我」這個聲音不算，自我定義才算。
- **個體** / Individual（37b3643a-dc40-4463-8b36-4f4594acd986.c20）：個體是被某個我分別出來的呈現。同一段宇宙，被分別為一個個體或許多個個體，皆成立。
- **同一** / Identity（37b3643a-dc40-4463-8b36-4f4594acd986.c21）：同一是一種分別：某一時刻的渦與另一時刻的渦是不是同一個，由作出分別的我決定。一個呈現是不是渦，不是分別；兩個時刻的渦是不是同一個，是分別。
- **流變律** / Law of Flux（37b3643a-dc40-4463-8b36-4f4594acd986.c24）：流變律是框架承認的一條鐵律，不由其他任何條件推出：一個渦所在的歷史一直在變；在它的每一個時刻，到達它的歷史都和該次坍塌之前不同，永遠不會一模一樣。
- **黑箱律** / Law of the Black Box（37b3643a-dc40-4463-8b36-4f4594acd986.c25）：黑箱律是框架承認的一條鐵律，不由其他任何條件推出：一個渦在某個時刻不被鎖死時，宇宙中沒有任何渦能在那一刻之前唯一推出它的下一時刻，包括它自己。能推出的是權重，不是結果：各結果的權重由到當時為止的歷史決定。
- **損耗律** / Law of Attrition（37b3643a-dc40-4463-8b36-4f4594acd986.c26）：損耗律是框架承認的一條鐵律，不由其他任何條件推出：任何一個我，在任何時刻都不能完全分別自己；它對自己的分別永遠落後一步。
- **復原** / Restoration（37b3643a-dc40-4463-8b36-4f4594acd986.c27）：復原一個渦，是讓它自己的那一段歷史再發生一次。
- **不可復原律** / Law of Non-Restoration（37b3643a-dc40-4463-8b36-4f4594acd986.c28）：不可復原律是框架承認的一條鐵律，不由其他任何條件推出：在宇宙之內，沒有任何渦能復原一個渦，包括它自己。它有兩層。第一層是位置：歷史中的每一個位置只發生一次，任何看起來相同的一段，都發生在歷史中的另一個位置。第二層是內容：一段歷史中不被鎖死時作出的選擇，沒有任何渦能保證在同樣不被鎖死之下再作出一樣的選擇；全由約束決定的一段，不在第二層之內。
- **寫入** / Writing（37b3643a-dc40-4463-8b36-4f4594acd986.c29）：寫入是每一次坍塌之前先發生的一筆加入歷史的內容。寫入的內容，完全由到當時為止的歷史決定。一次寫入可以作為刺激落到呈現上；渦的每一次分別，都在歷史中留下一次寫入。
- **刺激** / Stimulus（37b3643a-dc40-4463-8b36-4f4594acd986.c30）：刺激是一次寫入對某個呈現而言的那一部分：把一次寫入看成給該呈現的東西，就是它收到的刺激。一次寫入可以不落到某個呈現上。渦的分別也作為刺激被寫入。

## 《四條律相關工具及範例》

UUID：b9df3b68-23ee-4839-965b-ed0e6b283ee6

- **不會發生** / Never Occurs（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c01）：不會發生是禁止的一種形式：它說某件事不會發生；被禁止的事只要出現一次，這條禁止就被推翻。
- **不被保證** / Not Guaranteed（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c02）：不被保證是禁止的一種形式：它不說某件事不會發生，而是說框架不斷言它必然發生。具體情形中是否另有約束使它成立，框架也不斷言；要主張它必然發生，必須另外寫明所依賴的約束。它限制的是預測能有多少信心。
- **對他者認識的不可完備性** / Incompleteness of Knowing Others（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c19）：對他者認識的不可完備性是這個結論：沒有任何我能保證自己分別完了另一個渦。我只能用已經到達它的歷史來分別對方；對方的訊息到達它是一件事，它的分別又是另一件，在兩者之間，對方的歷史仍可能增長，而對方不被鎖死時，對方下一時刻的結果不能事先推出（黑箱律）。此外，對方自己的那一段中只到達對方的部分，沒有任何東西保證也會到達它；而它的分別作為一次寫入，一旦成為對方自己的那一段的一部分，也可能改變對方下一時刻的權重。
- **時鐘時間** / Clock Time（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c21）：時鐘時間是渦以時鐘量到的時間，依物理，不形式化。它與時刻不同：時刻只是坍塌的次序，任何渦都量不到。
- **重切** / Recutting（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c22）：重切是改變切法：把一個部分切成許多部分，或把許多部分合成一個。「結論經得起重切」只適用於結果投影相容的重切：同一段宇宙被描述成較粗與較細的呈現時，較粗呈現的結果投影可由較細呈現的結果投影經某映射取得。迴路、知見障、耦合、太極與更新所得的結論，在這些結果投影相容的重切下都必須不變；印象不受此要求。在這些相容重切之下，權重與推論不變；耦合、太極與印象在描述迴路之間的關係時，若相關部分被合併，這些關係轉為內部結構，不再以關係的形式出現。任意兩個切法之間是否滿足這項結果投影相容條件，不由此定義保證。
- **切法** / Cut（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c23）：切法是分析者的一次分別：把哪一段宇宙看作一個迴路。敘述迴路必須切出部分，所以切法無法避免，必須講明。
- **節點** / Node（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c25）：節點是切法下的一個呈現，是假名。節點有三類：渦、信號容器、隨機源。
- **信號容器** / Signal Container（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c26）：信號容器是這樣的節點：它不是渦，從這一時刻起每一步都被鎖死。它通常持續存在，在許多時刻向渦輸出，但這不是條件。它的內容可以由渦寫下，例如書、法條；也可以來自其他呈現，例如望遠鏡帶來的觀測。知見障對它沒有內容；它也不能成為印象的對象。
- **隨機源** / Random Source（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c27）：隨機源是這樣的節點：它不是渦，但這一時刻或之後至少還有一個時刻它不被鎖死。例如擲出的骰子、放射性衰變的原子。它不被鎖死時，只能談權重；它也不能成為印象的對象。
- **輸出** / Output（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c28）：輸出是一個呈現的坍塌結果，以及它的分別內容。
- **邊** / Edge（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c29）：邊是節點之間有向的關係：一個節點的輸出，參與另一個節點的權重。邊本身不帶大小：一條邊影響多大，取決於接收者的歷史，不是邊本身的屬性。
- **迴路** / Loop（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c31）：迴路是這樣的結構：一個呈現的輸出，經由自己或其他呈現，又參與它自己的權重。迴路一律指在講明的切法下的迴路；跨時刻持續存在是不被保證的。
- **正回饋** / Positive Feedback（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c32）：正回饋是迴路的一種作用：迴路自己的一次輸出繞回來，把權重推向產生這次輸出的那個方向。方向必須包含這次輸出，由它錨定；方向劃得多粗，屬於切法。
- **負回饋** / Negative Feedback（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c33）：負回饋是迴路的一種作用：迴路自己的一次輸出繞回來，把權重推離產生這次輸出的那個方向。方向必須包含這次輸出，由它錨定；方向劃得多粗，屬於切法。抵抗若來自另一個迴路的輸出經由耦合壓過來，不是負回饋。
- **速度** / Loop Speed（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c34）：速度是迴路繞一圈要多久，以時鐘時間計，與時刻不同。
- **知見障** / Cognitive Obscuration（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c35）：知見障是這件事：一個呈現在下一時刻各個結果的權重，總和為一，所以推高一個方向，必然壓低其餘方向的總和。一切學習都有代價，知與障是同一件事。知見障只保證此消彼長，不決定一筆到達推高哪個方向、推高多少。
- **耦合** / Coupling（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c36）：耦合是這樣的情形：兩個或多個呈現的自己的那一段，在一個講明的到達上重疊。參與耦合的可以是渦，也可以是由許多呈現構成的迴路。重疊有兩種方式：同一件事到達它們，例如同一個輸出，或宇宙初態；或者它們的輸出互相到達。耦合總是相對於一個講明的到達而言。
- **趨同** / Convergence（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c37）：趨同是耦合之下的一種走向：在一個講明的維度上，參與者輸出的模式之間的距離縮短。
- **趨異** / Divergence（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c38）：趨異是耦合之下的一種走向：在一個講明的維度上，參與者輸出的模式之間的距離拉長。
- **太極** / Taiji（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c39）：太極是這樣的結構：兩個方向相反的正回饋迴路互相耦合，在耦合中趨異，形成動態平衡。每一方的輸出到達另一方，都強化了另一方自己的方向，所以任何一方壯大，都在餵養對方。太極發生在迴路與迴路之間，不要求每個參與者都是渦；「方向相反」必須講明是在哪一個維度上判斷。
- **一方退出** / Withdrawal of One Side（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c40）：一方退出是太極結束的一種方式：其中一方的渦大多退場，或者它不再自我強化。
- **合流** / Merging（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c41）：合流是太極結束的一種方式：耦合的走向由趨異轉為趨同，兩個迴路合成一個。在重切之下，這也可以看作兩個迴路被切成了一個。
- **更新** / Renewal（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c42）：更新是渦的進出：有些渦退場，有些呈現進場。
- **退場** / Exit（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c43）：退場是一個渦不再是渦：它在某一時刻是渦，在它的下一時刻不是渦。
- **進場** / Entry（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c44）：進場是一個呈現開始成為渦：它在某一時刻不是渦，在它的下一時刻是渦；或者在它的第一個時刻就是渦。
- **印象** / Impression（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c45）：印象是一個我對一個渦的分別，也就是它對那個渦的權重的估計。對象可以是另一個渦，也可以是這個我自己，此時是自我印象。對渦的一切統計估計，包括史料的統計，都屬於印象。印象的材料有三個來源：對方過去的輸出；我自己和對方重疊的那一段；對方所在的耦合，例如角色、制度、信仰。
- **自我印象** / Self-Impression（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c46）：自我印象是對象為自己的印象：一個我對自己的分別。
- **份量** / Impact（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c47）：份量是一筆到達能移動多少權重，是生成函數內部的事。份量不能相加：一筆到達的效果，取決於它之前的歷史。
- **頻率** / Frequency（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c48）：頻率是到達多常發生。它是應用時必須寫明的份量假定之一。
- **歧異度** / Discrepancy（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c49）：歧異度是一筆到達和接收者過去收到的東西差多遠。它是相對於接收者的歷史而言的：同一個到達，落在不同的渦上，歧異度可以完全不同。它是應用時必須寫明的份量假定之一。
- **應用假定** / Application Assumption（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c50）：應用假定是這個假定：在生物學與社會科學的層次上，一個呈現的下一時刻若不能由那個層次可得的歷史唯一推出，就假定它不被鎖死。它不是定理。
- **經驗禁止** / Empirical Prohibition（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c51）：經驗禁止是從案例中提煉出的必要條件：缺少某個條件時，某個結局不會發生。它不是由框架推出，而是由跨案例的校準得來，必須標明，並可以被新的案例修改。它只寫必要條件，不寫充分條件：條件都滿足時，也只能說那個結局的權重變重。
- **持平** / Stasis（b9df3b68-23ee-4839-965b-ed0e6b283ee6.c52）：持平是耦合之下的一種走向：在一個講明的維度上，參與者輸出的模式之間的距離不變。

## 《三重幻覺與被迫的賭注》

UUID：fb0addca-42b6-4884-aa18-438c695747ab

- **二階分別** / Second-Order Distinction（fb0addca-42b6-4884-aa18-438c695747ab.c01）：二階分別是一個我的一次分別：它對自己的某一次分別再作分別，把那一次劃為「這是看法，不是被看的東西」。只作一階分別的我，照著看法與被看的東西的區分行動，卻不作出這個區分；二階分別把它作出來。二階分別的對象是自己的分別，不是別人的。說一個我有二階分別，指它能對自己的任何一次分別作這樣的分別。
- **看法歸屬** / View Attribution（fb0addca-42b6-4884-aa18-438c695747ab.c02）：看法歸屬是一個我的一次分別：它把到達它的一筆輸出，劃為另一個我的一次分別：「這是對方的看法，不是被看的東西」。看法歸屬可能歸錯：被劃為看法的那筆輸出，不一定來自一個我。它不是印象：印象估計對方的權重，看法歸屬只把對方的一筆輸出劃為看法。它的對象是別人的分別，這一點與二階分別不同。
- **回合** / Round（fb0addca-42b6-4884-aa18-438c695747ab.c04）：回合是一個呈現在它的一個時刻中走過的一圈：到達它的歷史參與它的權重，權重落出一個結果，這個結果成為歷史，再到達它。回合只有這四環：到達、權重、結果、再到達；落出結果之前的那一段不分析，也不說它是空的。
- **計算** / Computation（fb0addca-42b6-4884-aa18-438c695747ab.c05）：計算是這樣的回合：它被鎖死，只可能有一個結果，由約束定死；或者它不被鎖死，可能的結果不只一個，但到達它的歷史並不都參與它的權重。前者稱為鎖死的回合，後者稱為隨機的回合。是不是計算，按每一個回合判定，不按呈現判定。
- **決定** / Decision（fb0addca-42b6-4884-aa18-438c695747ab.c06）：決定是渦在不被鎖死時的回合：到達它的整段歷史都參與它的權重，而權重定不出結果。是不是決定，按每一個回合判定，不按呈現判定。
- **三問** / Three Questions（fb0addca-42b6-4884-aa18-438c695747ab.c07）：三問是這三個問題：你從哪裡來？你是誰？你要做什麼？它們分別追問一個我的來處、它自己，以及它的下一刻。問這三個問題，指把自己在這三個方向上的答案劃為看法，而不當作被看的東西本身。
- **來路牆** / Wall of Provenance（fb0addca-42b6-4884-aa18-438c695747ab.c08）：來路牆是這個結論：一個我拿不全自己過去的歷史。它包含三點：一、一個我手上只有已經到達它的歷史；一件事當時沒有到達它，之後也不會到達它，之後到達的只是那件事留下的影響，是另一件事。二、一個我對自己來處的分別，會到達它自己，成為它自己的那一段的一部分；追問來處，就增添了來處。三、自己的那一段不能再發生一次拿來對照（不可復原律）。適用範圍：一切我。
- **盲點牆** / Wall of the Blind Spot（fb0addca-42b6-4884-aa18-438c695747ab.c09）：盲點牆是這個結論：一個我看不見現在的自己。它包含三點：一、沒有任何我能在任何時刻完全分別自己，正在作出的那一次分別不在它自己的材料裡（損耗律）。二、對自己的分別會到達自己，成為自己的一部分，所以看自己就改變了自己。三、要看的那個自己由分別劃出，不同時刻的我是不是同一個，也是一次分別（同一）。適用範圍：一切我。
- **未定牆** / Wall of the Undetermined（fb0addca-42b6-4884-aa18-438c695747ab.c10）：未定牆是這個結論：一個我算不出未來的必定。它包含兩點：一、一個我在不被鎖死的時刻，事先不能唯一推出自己下一個決定的結果，至多推出自己的權重（黑箱律）；權重的分布會重複出現，不被保證。二、決定落出以後，別人與環境會怎麼回應，一個我事先算準，不被保證。適用範圍：第一點為一切我在不被鎖死的時刻；第二點為一切我。
- **被迫的賭注** / Forced Wager（fb0addca-42b6-4884-aa18-438c695747ab.c11）：被迫的賭注是這個結論：一個渦的每一個決定，事先算不準，事後收不回，而且不能不作。算不準：決定的結果不能事先唯一推出，結果落出以後世界的回應，事先算準也不被保證。收不回：歷史中的每一個位置只發生一次，重來而作出一樣的選擇，沒有任何渦能保證。不能不作：渦只要在某個時刻不被鎖死，那一刻就有一個決定；「不動」也是那一回合落出的結果之一。適用範圍：一切渦在不被鎖死的時刻。
- **卡住** / Deadlock（fb0addca-42b6-4884-aa18-438c695747ab.c12）：卡住是一個我的這種情形：候選之間的權重分不出高下，自我說服推不動而一再重來，結果卻照樣落下。
- **有損** / Lossiness（fb0addca-42b6-4884-aa18-438c695747ab.c13）：有損是到達一個我的東西的這種性質：它不是完整的被看的東西。完整的被看的東西，指被看的東西的自己的那一段的全部。
- **幻覺** / Illusion（fb0addca-42b6-4884-aa18-438c695747ab.c14）：幻覺是一個我的這種處境：它據以行動的，是有損地到達它的東西，不是被看的東西本身。幻覺是處境，不是失誤；一個看法事後被證實或被證偽，不改變它是不是幻覺。
- **世界幻覺** / World Illusion（fb0addca-42b6-4884-aa18-438c695747ab.c15）：世界幻覺是幻覺落在來處上的形態：把到達自己的歷史當成世界本身；把對來處的分別當成來處本身。
- **自我幻覺** / Self Illusion（fb0addca-42b6-4884-aa18-438c695747ab.c16）：自我幻覺是幻覺落在自己上的形態：把自我印象當成自己；把不同時刻的我是同一個當成本來就是那樣，而不是一次分別（同一）。
- **決策幻覺** / Decision Illusion（fb0addca-42b6-4884-aa18-438c695747ab.c17）：決策幻覺是幻覺落在下一刻上的形態：把權重的估計當成結果；把決定中算得出的那一段，當成結果的擔保。
- **候選** / Candidate（fb0addca-42b6-4884-aa18-438c695747ab.c18）：候選是一個我作出的一次分別：把某些可能劃為一個選項。候選是分別，不是分支：權重分配在分支上，候選只是我對分支的一種劃分。
- **自我說服** / Self-Persuasion（fb0addca-42b6-4884-aa18-438c695747ab.c19）：自我說服是一個我在決定的結果事先算不準時，用自己的分別把自己推向某個候選；這些分別到達自己，參與之後的權重。說服的一方與被說服的一方，是同一個我。
- **權力** / Power（fb0addca-42b6-4884-aa18-438c695747ab.c21）：權力是一個我的輸出以高頻率、廣範圍到達其他的我，參與它們的權重。
- **死亡** / Death（fb0addca-42b6-4884-aa18-438c695747ab.c22）：死亡是一個我替一個渦標上「它已經退場」的一次分別。死亡是描述，不是物理條件；標在哪裡，由作出標記的我判定。
- **三道牆** / Three Walls（fb0addca-42b6-4884-aa18-438c695747ab.c23）：三道牆是來路牆、盲點牆、未定牆三者的總稱。
- **一階分別** / First-Order Distinction（fb0addca-42b6-4884-aa18-438c695747ab.c24）：一階分別是渦的分別中的一種：它照著看法與被看的東西的區分行動，卻不作出這個區分，也就是不把任何一次分別劃為「這是看法，不是被看的東西」。一階分別是能力的指標：只具有一階分別的渦，是不作二階分別的渦。沒有「一階的我」這種我，只有只具有一階分別的我。
- **鎖死的回合** / Locked-in Round（fb0addca-42b6-4884-aa18-438c695747ab.c25）：鎖死的回合是鎖死的回合：只可能有一個結果，由約束定死。它是計算的一種。
- **隨機的回合** / Random Round（fb0addca-42b6-4884-aa18-438c695747ab.c26）：隨機的回合是這樣的回合：它不被鎖死，可能的結果不只一個，但到達它的歷史並不都參與它的權重。它是計算的一種。
- **被看的東西** / What Is Seen（fb0addca-42b6-4884-aa18-438c695747ab.c27）：被看的東西是一次分別所劃出的那個呈現。
- **我的建構** / Construction of the Self（fb0addca-42b6-4884-aa18-438c695747ab.c28）：我的建構是一個我以分別劃出自己的過程。劃的材料分兩類：外來的，即到達它的歷史，以及別人對它的分別；自身的，即它自己過去對自己的分別。

## 《互動動力學-共同外生背景下的二階網路》

UUID：ae79e938-76e1-4bf9-b2ab-995c03e16c9e

- **配置假定** / Configuration Assumption（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c01）：配置假定是對一組具體對象所作的假定：在講明的階段，其中某些對象只具有一階分別，其餘對象有二階分別，也有看法歸屬。配置假定不是定理。從外部確認某個對象某一刻有沒有二階分別，不被保證；只有找到機制，證明該對象的輸出只能由鎖死的回合落出，或只能由隨機的回合落出，「對象具有二階分別」這一半的假定對它才不成立。
- **外生背景** / Exogenous Background（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c02）：外生背景是在講明的時窗與切法下，視為從模型外部進入、不隨模型中的迴路更新的背景。它是範圍上的設定，不主張背景不變；進入模型的是背景，不是各個我從中取得的內容；每個我只拿得到到達它自己的那一部分，各個我取得的內容可以不同。
- **驅動力不可確認** / Unconfirmability of Drives（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c03）：驅動力不可確認是這個結論：對不被鎖死的對象，它的驅動力，也就是動機、需求與目的，從外部不能被完整觀測，不能被對象自己的自述確認，旁人事後對動機的判斷也只是看法歸屬或印象，不能算證實；動機本身不憑自身到達旁人。適用範圍：一切不被鎖死的對象，不分年齡，也不分有無二階分別；從外部無法確認對象是否被鎖死，只能假定。
- **二階網路** / Second-Order Network（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c04）：二階網路是由具有二階分別與看法歸屬的我，以及它們之間的耦合所構成的集合：一個我對另一個我的輸出作看法歸屬，而不只把它當成一筆輸出來反應；每個參與者在參與的那一刻，既有二階分別，也有看法歸屬，兩者缺一不可。參與者至少兩個，但不必同時在場：寫下內容的一方，在寫下的那一刻是參與者，之後退場不影響這一點。網路在歷史中形成的規律，包括規範與制度，是它的模式，不是另一類實體。
- **專屬歷史** / Dedicated History（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c05）：專屬歷史是兩個我之間，在一個講明的維度上，彼此互相到達的輸出所構成的那一段歷史，只屬於這兩者。
- **默契** / Tacit Coordination（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c06）：默契是在指定的情境類型與維度中，兩個我經歷反覆的專屬歷史，在可比較的情境下，呈現不必每次重新逐項指導、仍能相容接續的行為模式。判準是歷史與行為模式，不是預言：它不要求任何一方事先算準對方的下一步，不要求友善，不要求彼此透明，也不要求一方對另一方的印象穩定。互動次數多，不等於已有默契。
- **指定協調** / Specified Coordination（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c07）：指定協調是這樣一種判準：對一項已界定的任務，依明列的驗收條件，檢查某段實際發生的行動序列；序列符合驗收條件，稱這段序列在該任務上呈現協調。任務是研究者指定的判準，不是參與者驅動力的代名詞；成功也不等於關係改善或彼此理解。
- **失配** / Mismatch（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c08）：失配是在研究者指定的維度與相容判準下，兩個我相鄰的輸出序列不相容。判準看的是序列相容與否，不是任何一方想要而沒得到，也不是期待被違反。
- **修復** / Repair（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c09）：修復是失配之後，在同一維度與同一相容判準下，後續輸出序列重新相容。修復只是序列的記錄，不表示歸屬得到了檢驗，也不表示任何一方得到了想要的，也不表示關係改善。
- **衝突** / Conflict（ae79e938-76e1-4bf9-b2ab-995c03e16c9e.c10）：衝突是在研究者指定的維度與時窗內，兩個我之間形成的太極：雙方的輸出都針對對方在該維度上的輸出，方向相反，而且每一方的輸出到達對方，都強化對方自己的方向。至少一方的輸出已到達對方（含經由轉述），才可能形成。各做各的相反方向、沒有針對對方的輸出，不是衝突。衝突是對序列的描述，不是對任何一方內在狀態或驅動力的描述。

## 《互動動力學-陌生人迴路中的專屬歷史變動與更新》

UUID：2ccbf179-58cf-4851-bd72-5fa886e4b2c3

- **單元** / Unit（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c01）：在一次切法下，兩個渦、各自的小迴路，以及把兩者連起來的大迴路所構成的結構。單元必須講明在哪個維度上判斷。信號容器與隨機源可以接在單元的邊上，但不是單元的主體。
- **小迴路** / Small Loop（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c02）：一個渦的輸出回到自己的歷史、參與自己之後的權重的迴路。只有渦有小迴路；信號容器與隨機源沒有。
- **大迴路** / Large Loop（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c03）：連接兩個渦的迴路：甲的輸出到達乙，乙的輸出到達甲，各自參與對方之後的權重。
- **學習** / Learning（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c04）：到達的材料累積進歷史、可能改變後續權重的過程。學習是結果條件，不指目的，沒有預設方向，不保證學到，也不保證學對。判定只看到達之後可觀察的輸出有改變，不證明改變來自哪一筆輸出。
- **結果回饋** / Outcome Feedback（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c05）：一個渦之後的輸出再到達自己的後續互動，帶回實際後果。事前學習的方向不可預測，事後的結果可以判；判準在其他節點與自然環境的反應結果裡，不在發生學習的渦內部。
- **退出成本** / Exit Cost（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c06）：一個我讓一條邊上的到達停止或減少時，要承受的結果回饋。每一端各算各的，可以不對稱。成本低，就是可以輕易放棄這條邊；成本高，就是幾乎不得不繼續。退出成本的層級是邊，與節點層級的退場不同，兩者不互相蘊含。
- **可達子圖** / Reachable Subgraph（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c07）：以某個渦為中心，在講明的時窗內，所有曾有輸出到達它的呈現，連同這些呈現與它之間的邊所構成的子圖。只計已到達者。每個渦各有一張。
- **大型節點** / Large Node（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c08）：在講明的切法與時窗內，輸出到達的節點數極大、幾乎涵蓋所指範圍內每一個節點的節點，例如政府、公眾人物、大型企業。它是真實存在的節點；到達廣不蘊含影響大，不蘊含全知，也不蘊含有目的。
- **共振** / Resonance（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c09）：在講明的維度與時窗內，多個節點的輸出模式反覆相容接續。共振須以到達為條件：節點彼此之間有到達，或有共同的來源（例如信號容器、自然環境）對它們都有到達；完全沒有到達，就沒有共振。判準是相容，也就是失配的反面，不是距離；因此不等於趨同。是否共振，只能事後說。共振不同於默契：默契是兩個我之間按維度計的專屬歷史上的相容接續，共振不要求專屬歷史，也不限兩個我。
- **懲罰** / Penalty（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c10）：一個輸出之後，到達輸出者的、在講明的判準下算作代價的結果回饋。判準須講明是誰的：輸出者自己的分別，或研究者的判準，兩者可以不一致。懲罰不一定是暴力，不一定被明列。
- **強制** / Enforcement（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c11）：已被明列成規則、寫在信號容器裡、違反可由第三方判定的懲罰。懲罰可以是暴力，也可以不是。強制不保證遵守，也不保證違反被判定與執行；規則先於違反，是另一個時間點的事。
- **容錯率** / Fault Tolerance（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c12）：在講明的維度上，一個我對對方的失配所能容忍的程度的上限；超過上限，這條邊就可能終止。
- **文化** / Culture（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c13）：研究者對網路中出現的共振的命名。在指定的切法、維度與時窗下，它是無數單元在特定自然環境約束下，經過反覆的輸出、到達與結果回饋，留在歷史中的一組相容圖樣：哪些維度組合能不被反覆打斷地接續下去。文化不以是否寫下來為界，沒有主體，不被某人持有或傳遞，也沒有尺度。
- **模板** / Template（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c14）：抽象化、可重複使用的規則或資料，被明列在信號容器裡。容器被鎖死，內容不會自己變，在某維度上提供固定點，不需要先共振就能取得。同一規則有兩份文本就是兩份模板。模板是容器裡的固定內容，不是文化的一層。模板的有無依研究者指定的判準判定。
- **崩潰** / Collapse（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c15）：在指定尺度、維度與時窗下，原來的秩序失去了；秩序指不必逐次指導就能相容接續的預設與接續模式。事後的分別，由作判斷的我劃定。崩潰有程度、逐維度，沒有尺度。崩潰與失配、退場判準不同，可為成因或形態，不互相蘊含。
- **自然環境** / Natural Environment（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c16）：在講明的切法下，不屬於模型中任何節點、卻有輸出到達這些節點的部分，包含物理條件，例如地形、氣候、水與食物。它對各節點最基本的行為構成約束。
- **落空比例** / Proportion of Failed Expectations（2ccbf179-58cf-4851-bd72-5fa886e4b2c3.c17）：在指定的維度與時窗下，事後統計的、原本相容的接續中未能接上的比例。它是外顯統計，不是真實權重的讀數。

## 《生產動力學》

UUID：96f10d75-23d0-441f-94c7-ab87ca28d284

- **生產** / Production（96f10d75-23d0-441f-94c7-ab87ca28d284.c01）：生產是研究者對輸出歷史所作的一種分別：在講明的切法下，把某段輸出看作生產。生產不賦予輸出獨立本體。
- **狀態變數** / State Variable（96f10d75-23d0-441f-94c7-ab87ca28d284.c02）：研究者在講明的切法下，為節點指定的一種可記錄變數，用來描述該節點下一刻的樣子，並供退場判準表述。什麼算狀態，隨節點邊界而定，是切法下的歸類，不是事物本身的性質；常以「在該節點的視角下不可轉移、不可儲存」作為辨認依據，但這只是依據，不是定義。
- **資源變數** / Resource Variable（96f10d75-23d0-441f-94c7-ab87ca28d284.c03）：研究者在講明的切法下，為節點指定的一種可記錄變數，其值在每個推演輪中可增可減，由實際事件決定。什麼算資源，隨節點邊界而定，是切法下的歸類，不是事物本身的性質；常以「在該節點的視角下可轉移、可儲存」作為辨認依據，但這只是依據，不是定義。記錄資源變數的增減，不預設不同節點的增減對應同一份東西。
- **退場判準** / Exit Criterion（96f10d75-23d0-441f-94c7-ab87ca28d284.c04）：研究者在講明的切法下，用狀態變數表述的一條準則，用來判定節點在某個推演輪中是否判準退場。判準是研究者的一次分別，是定義；是否判準退場是該推演輪實際的狀態事件，是事實，兩者不互相替代。判準可以是上游所稱的「不再是渦」，也可以是研究者明示的其他定義。判準退場是《生產動力學》自己的概念，指依研究者所訂判準記為退出；它與上游的退場（不再是渦）不同，兩者可以一致，也可以不一致。
- **解** / Solution（96f10d75-23d0-441f-94c7-ab87ca28d284.c05）：研究者在講明的切法下，記錄的各節點下一刻的狀態變數、資源變數，以及依退場判準所記的是否判準退場，合起來是該推演輪的解。判準退場只是解的一個維度，與其他維度並列；沒有記錄的東西不在解裡，但仍在歷史中。
- **推演輪** / Derivation Round（96f10d75-23d0-441f-94c7-ab87ca28d284.c07）：推演輪是研究者在講明的切法下，把一個模型往前推進一次的單位：在場的各節點各自走一次上游的輸出、到達、入歷史的循環，再加上研究者所作的記錄，以及成員依判準退場與進場所作的成員變動。單位是整個切出的範圍，不是單一節點。記錄的內容與成員變動的規則由使用者指定，不假定各節點同步，推演輪只是排序。
- **判準退場** / Criterion Exit（96f10d75-23d0-441f-94c7-ab87ca28d284.c09）：在講明的切法下，依研究者所訂的退場判準，某節點在某個推演輪被記為退出。判準退場是《生產動力學》自己的概念，不等於上游的退場（不再是渦）：判準可以取上游的「不再是渦」，也可以取退休、離職、公司解散或生理界線等其他明示定義，所以兩者可以一致，也可以不一致。是否判準退場是該推演輪實際的狀態事件，是事實；判準本身是定義。

## 《生物人個體輸出傾向動力學》

UUID：81952268-47b1-4d8c-9605-270c42646693

- **要能果三問** / Want-Can-Outcome Questions（81952268-47b1-4d8c-9605-270c42646693.c01）：關於一個個體的三個問題；這裡的個體是生物人，屬上游所稱的我：能自述，也能對自己作分別。對這樣的個體，個體層的問題只有這三個：它要什麼，對應權重與輸出傾向，研究者單憑記錄讀不出權重的值，只能統計輸出的記錄；它能不能做到，對應門檻；做完會變成什麼樣，對應輸出到達外界之後外界的回應、時窗終點的記錄，依判準退場所記的存續，以及依另訂的事件判準所記的生殖（生殖不屬上游「解」的維度）。三問各自問不同的事：要什麼推不出能不能做到，能做到推不出會做，做了推不出結果是所要的。
- **輸出傾向** / Output Tendency（81952268-47b1-4d8c-9605-270c42646693.c02）：研究者對輸出的記錄中反覆可見的形狀所作的歸納，描述一個個體在指定切法下傾向做出哪一類輸出。它是在指定的切法、時窗、分類規則與門檻條件下作的歸納。分類規則是研究者的分別，所歸的類別不是行為本身自帶的界線。輸出傾向是記錄的形狀，與權重的關係只能是估計，不是權重的讀數。
- **門檻** / Threshold（81952268-47b1-4d8c-9605-270c42646693.c03）：一條輸出路徑成立所需的一組前件。路徑是研究者在指定切法下劃出的一類輸出序列；前件是路徑成立所需的各項條件，可以是身體素質、知識、時間、位置、外界條件、工具與資源，記在哪一類由研究者講明（見狀態變數、資源變數）。任一前件不具備，該路徑在該輪不可行；全部具備只表示可行，不表示會發生。
- **異途結果同類** / Same Outcome from Different Paths（81952268-47b1-4d8c-9605-270c42646693.c04）：研究者依明示的結果變數、時窗與容許區間，把不同個體各自不同的輸出歷程所得的結果，歸入同一類。這是研究者的外部歸類；它不是趨同（趨同指耦合之下，指定維度上參與者輸出模式之間的距離縮短）。結果同類不推出路徑相同，也不推出內部問題或驅動力相同；它也不提供發生頻率。
- **機會成本** / Opportunity Cost（81952268-47b1-4d8c-9605-270c42646693.c05）：研究者在自己指定的估值下，對同一輪中已走路徑的終點與被排除路徑的預期終點所作的比較。被排除路徑限於與已走路徑互相排斥、且門檻具備者；它們沒有發生，其終點只能是依某個依據作的估計，沒有依據時終點未知。機會成本是研究者的比較計算，不是個體的量，也不屬於權重。
- **記錄** / Record（81952268-47b1-4d8c-9605-270c42646693.c06）：研究者在講明的切法下，依自己的需要選取、對已發生之事所作的登記；記什麼由研究者的登記動作決定，不預先列舉內容。常見的有時窗內實際發生的輸出、起點與終點的狀態變數、資源變數，以及判準退場是否發生；所記的內容可以包括發生了什麼、何時、何地、幾次、間隔多久。只登記已發生的事；沒登記的輸出仍在歷史裡，可能繼續影響權重。自述登記為一筆輸出，與其他輸出同地位。路徑的門檻是研究者的判斷，可標「未知」，與記錄並列附上，不算記錄。
- **路徑** / Path（81952268-47b1-4d8c-9605-270c42646693.c07）：研究者在指定切法下劃出的一類輸出序列。怎麼劃是研究者的判定；路徑不是個體自己帶著的邊界。一條路徑在某一輪是否可行，看它的門檻。
- **前件** / Antecedent（81952268-47b1-4d8c-9605-270c42646693.c08）：一條路徑成立所需的各項條件之一，是門檻的組成項。可以是身體素質、知識、時間、位置、外界條件、工具與資源；記在狀態變數還是資源變數，由研究者講明，不先分類。
- **個體局部解** / Individual Local Solution（81952268-47b1-4d8c-9605-270c42646693.c09）：指定個體在所屬推演輪的下一刻狀態、資源，以及判準退場的相關記錄；若該個體已被列為指定切法的節點、這些欄位已記入該輪的解，則是上游解的單節點部分。
- **可行集合** / Feasible Set（81952268-47b1-4d8c-9605-270c42646693.c11）：某一輪中，門檻的各項前件都具備的路徑所成的集合。它回答的是物理上能不能，不回答會不會發生；前件隨歷史可能變動，所以每一輪的可行集合可能擴大、縮小或不變。
- **知識** / Knowledge（81952268-47b1-4d8c-9605-270c42646693.c13）：某條路徑的門檻中，無法直接檢查的前件，隨路徑而定（有廚師的知識，不推出有醫學的知識）。只能由該路徑上的輸出推測，記為「由輸出推測」或「未知」，不預設具備。身體與外部條件有可直接記錄的物理改變，可直接檢查，不在此列。
- **現存樣本條件化** / Conditioning on Existing Samples（81952268-47b1-4d8c-9605-270c42646693.c14）：研究者以「存續」（尚未發生判準退場）為條件選樣的做法：樣本裡只有尚未判準退場的個體。判準退場只取決於研究者所訂判準與實際事件，與輸出的好壞無必然關係，所以存續者的表現不足以直接用來評價好壞；已判準退場者留下的輸出，凡已到達別人或留在信號容器中者，仍在歷史裡，沒到達任何人者研究者可能拿不到，所以推不出消失者不可研究。這是研究者的樣本邊界，不是外界有選擇目的。
- **子代** / Offspring（81952268-47b1-4d8c-9605-270c42646693.c15）：某個個體的生殖事件所產生的、新進場的節點。

## 《生物人輸出格局動力學》

UUID：d244789a-9261-4a0d-a98a-feb8db56b511

- **存續判準** / Persistence Criterion（d244789a-9261-4a0d-a98a-feb8db56b511.c01）：研究者為某個要追蹤的結構（例如人群圖、經濟模式）講明的判準，用來判定它在各個檢查窗口中是否再次出現，包括同一性條件與檢查窗口兩部分。判準是研究者的定義；是否再次出現是該檢查窗口實際發生的事實，兩者不互相替代。
- **同一性條件** / Identity Condition（d244789a-9261-4a0d-a98a-feb8db56b511.c02）：存續判準的一部分：研究者講明，在什麼等價條件下，不同檢查窗口中的結構算作同一個。
- **檢查窗口** / Check Window（d244789a-9261-4a0d-a98a-feb8db56b511.c03）：存續判準的一部分：研究者講明，在哪些窗口中檢查某個結構是否再次出現。不同的結構各依自己的檢查窗口判定，不假定共同的輪次。
- **外界** / Exterior（d244789a-9261-4a0d-a98a-feb8db56b511.c04）：對某個節點而言，自己以外的一切到達來源，包含其他節點與自然環境。外界是相對的，換一個節點，外界就不同；節點的大小由切法決定，可以是一個人，也可以是一間公司；在一張輸出圖中，切法以外的一切都是這張圖的外界。
- **人群圖** / Population Graph（d244789a-9261-4a0d-a98a-feb8db56b511.c05）：在講明的切法下，生物人節點，以及它們之間的邊（一個節點的輸出，參與另一個節點的權重），加上各節點自己的迴路（自己的輸出，經由自己，又參與自己的權重）所成的靜態圖。人群圖的存續判準由研究者講明，方式同經濟模式。
- **輸出圖** / Output Graph（d244789a-9261-4a0d-a98a-feb8db56b511.c06）：在人群圖的基礎上，在講明的切法、維度與時窗內，把記錄附在點與邊上所得的圖：點是人群圖的節點，加上切法內的信號容器與隨機源；邊是人群圖的邊，加上這些信號容器、隨機源與其他節點之間的邊；各節點的輸出記錄附在點上，各次到達的記錄附在邊上，或附在節點自己的迴路上，來自外界的到達附在接收的點上；另外附上研究者對某節點某路徑的前件是否具備所作的判定，可以標「未知」。這項判定與記錄並列附上，不算記錄。切法內的信號容器與隨機源也是節點，與它們的邊一併記入。
- **輸出圖集** / Output Graph Set（d244789a-9261-4a0d-a98a-feb8db56b511.c07）：同一研究中，各時窗、各維度、各尺度的輸出圖所構成的集合。它是歷史的子集：沒有登記的輸出，以及「沒有發生在它身上」這類到達，都不在圖集上，但仍在歷史中，仍參與它們所到達的渦的權重。
- **格局傾向** / Pattern Tendency（d244789a-9261-4a0d-a98a-feb8db56b511.c08）：研究者對輸出圖集中反覆可見的結構所作的歸納，描述在指定切法下，傾向出現哪一類輸出圖結構。它是在指定的切法、時窗、分類規則與比較條件下作的歸納，不屬於任何節點，也不是任何節點權重的讀數；限定到單一節點、單一輸出類型，且該節點是一個個體時，就回到該個體的輸出傾向。
- **經濟模式** / Economic Mode（d244789a-9261-4a0d-a98a-feb8db56b511.c09）：依存續判準，在輸出圖集的多個檢查窗口中反覆出現的某一個以到達相連的結構。同一性看位置，不看是誰；可以只涉及單一節點，也可以跨節點；不限於市場，不分生產與消費、營利與否、有無貨幣。經濟模式帶有前件判定與逐檢查窗口的存續判準，這是它與共振的區別。經濟模式有同一性，可以判準中斷；格局傾向是跨圖的歸納，沒有同一性，也沒有中斷。經濟模式本身不是節點，是研究者對節點的輸出所作的歸類。
- **判準中斷** / Criterion Break（d244789a-9261-4a0d-a98a-feb8db56b511.c10）：依存續判準，某個被追蹤的結構（例如經濟模式、人群圖）在某檢查窗口內未再出現，即記為判準中斷。什麼算中斷，由判準決定；判準是研究者的定義；是否中斷是該檢查窗口實際發生的事實。判準中斷不等於崩潰、退場或判準退場，彼此不互相蘊含。
- **界面節點** / Interface Node（d244789a-9261-4a0d-a98a-feb8db56b511.c11）：經濟模式中有輸出到達外界的節點。類型依上游節點的分類，可以是渦、信號容器或隨機源；同一經濟模式可以有多種界面節點，外界經由不同界面接觸到的是性質不同的到達來源。
- **生殖模式** / Reproductive Mode（d244789a-9261-4a0d-a98a-feb8db56b511.c12）：產出子代的經濟模式。這是依產出所作的稱呼，是研究者的分別，沿用經濟模式的定義，沒有另外的成立條件。

## 《邊界的幻覺構件動力學》

UUID：08383b0a-1167-4efb-9b89-dc8a71afd5ff

- **幻覺構件** / Illusory Construct（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c01）：幻覺構件是這樣的構件：它的對象不由物理世界給出，卻被用來描述或組織輸出。例如我們，「丈夫」這類身分，以及二階能力。它有兩種出現方式：一、研究者用它描述複雜的一階輸出，把大量輸出歸成少數分別；二、它以名稱、宣誓、寫進信號容器的分類等形式出現在輸出中；這筆輸出若到達他人，便參與他人的權重。幻覺構件不是分別：分別是渦的動作，在歷史中留下寫入；幻覺構件是分別的內容，或描述與輸出中所用的構件。稱某構件為幻覺構件，不主張它的對象存在，也不否認。
- **二階能力** / Second-Order Capacity（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c02）：二階能力是同時具有二階分別與看法歸屬。它是兩者的合稱，不主張兩者是同一種能力；兩者的定義互不以對方為條件。具有二階能力，指能作這兩種分別，不指每一次分別都作了。二階能力是幻覺構件：它可用來簡稱複雜的一階輸出。
- **社會人** / Social Person（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c03）：社會人是具有二階能力的生物人。社會人是幻覺構件：稱某個生物人為社會人，是研究者以該生物人為對象的一次分別，其材料可以包含看法歸屬，依配置假定作出，對講明的階段成立。社會人指單一的生物人；由具有二階分別與看法歸屬的我及其間的耦合構成的集合，是二階網路，不是社會人。
- **我們** / We（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c04）：我們是一個社會人運用的幻覺構件：在某個維度上，把自己和被它歸為我的其他呈現，當成同一邊的一個單位，用來組織它的輸出。劃出我們，是一次用到這個構件的分別；我們的作用，只經由運用它的輸出；一個從未在輸出中運用的我們，和沒有劃出，在記錄中沒有差別。我們依對象定義：對象包含自己。它是單方面的，屬於運用它的社會人，不要求被劃進去的呈現也這樣劃。維度由劃的人劃出；同一對呈現可以在一個維度上被劃為我們，在另一個維度上不是。歸為我可以是對一個類的分別，不要求對類中每個成員都作過看法歸屬，要求的是有看法歸屬的能力，也不保證被歸為我的對象確實是一個我。劃出我們，不自動把其餘呈現劃為你們。
- **你們** / Plural You（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c05）：你們是一個社會人運用的幻覺構件：在某個維度上，把不含自己、被它歸為我的其他呈現，當成一個單位，用來組織它的輸出。劃出你們，是一次用到這個構件的分別；你們的作用只經由運用它的輸出。你們依對象定義：對象不含自己；與我們的差別在對象，不在內容。它是單方面的，屬於運用它的社會人，不要求被劃進去的呈現也這樣劃，也不要求它們劃出任何我們。維度由劃的人劃出；歸為我可以是對一個類的分別，不要求對類中每個成員都作過看法歸屬，要求的是有看法歸屬的能力，也不保證對象確實是一個我。
- **宣誓** / Avowal（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c06）：宣誓是一個社會人的一筆輸出，以接收者對宣誓者自己的分別為對象：在某個維度上，要接收者把宣誓者劃進某一類。宣誓只是要求，不是宣誓者自己分別的讀數：宣誓者有沒有這樣劃、劃得多深，不在記錄中；說謊也是宣誓。以對物的分別為對象的輸出不是宣誓；「這是我們的」若以對某物的分別為對象，不因字面上有「我們」就成為宣誓。把一筆輸出歸為宣誓，是研究者的看法歸屬。
- **對物的歸屬分別** / Belonging Distinction of Things（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c07）：對物的歸屬分別是一個社會人作出的一次分別：在某個維度上，以已經到達它的某物之呈現為材料，把該物劃為「我的」「你的」「我們的」或「你們的」。這四種說法是這次分別所用的幻覺構件，作用只經由運用它們的輸出，不是物本身具有的權利關係；它參照哪個我們或你們，屬於分別的內容。被劃為「我們的」的物，不因此成為另一個我。對物的歸屬分別不推出誰能使用、處置或分配該物，也不要求先劃出我們才作出；同一件物可以在不同維度上被同一社會人作出不同分別。
- **分別邊際** / Distinction Margin（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c08）：分別邊際是一個社會人在某個維度上作出分別，使對象在它的分別中落在不同一邊。把某些呈現劃為我們、另一些劃為你們，或把物劃為「我們的」「你們的」（對物的歸屬分別），都是分別邊際的例子。分別邊際只屬於作出它的社會人，不同社會人可以對同一批人、同一件物劃出不同的邊際；它不要求兩邊都有名稱。說經濟模式出現分別邊際，指社會人得以在該模式已到達它的材料上另作分別，不是經濟模式取得一個共有的內部分別。分別邊際只合稱既有的分別，它對他人與物的作用經由輸出與到達。
- **內外差異** / Inside Outside Difference（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c09）：內外差異是研究者在記錄中作出的一次分別：同類的輸出，在某組參與者之間，與在該組參與者和組外參與者之間，有所不同。哪些輸出算同類、哪些參與者算一組、在哪個維度上比較，由研究者在講明的切法下劃出；換一種切法，內外差異可以不同。研究者劃的組，與任何社會人劃的我們，範圍與維度不必一致。同類的輸出以某些物為對象時與以其他物為對象時有所不同，也是內外差異。內外差異只描述輸出的不同，不是規則、權利或制度。
- **宣稱界線** / Claimed Boundary（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c10）：宣稱界線是研究者在記錄中作出的一次分別：依一筆以分類為內容的輸出，劃出它所提出的界線。這類輸出包括宣誓、對人或對物的分類聲明，以及寫進信號容器的分類，例如法條、證書、規章。一筆輸出提出了哪條界線，由研究者依該輸出劃出，並在講明的切法下判定；它不是輸出者分別的讀數。宣稱界線與內外差異都依記錄中的輸出劃出，不是被研究的社會人的分別。
- **界線的移動** / Boundary Shift（08383b0a-1167-4efb-9b89-dc8a71afd5ff.c11）：界線的移動是研究者在記錄中作出的一次分別：比較兩個檢查窗口，把內外差異或宣稱界線在兩者之間的不同，記為界線的移動。移動在記錄中的結構可以依輸出描述，例如兩邊有差別的輸出互相強化；多人有差別的輸出由相容轉為不相容，內外差異變淡；某個參與者所受的輸出，由一邊的樣子轉為另一邊的樣子；宣稱界線與內外差異之間的距離拉長或縮短。在講明的維度上，這些結構可以用趨同、趨異、持平、太極與合流描述。同一段記錄換一種切法，可以記為移動，也可以記為不動。
